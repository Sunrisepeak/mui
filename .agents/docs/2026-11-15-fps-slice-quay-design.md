# FPS 纵切：Quay（M6.4 收尾）设计

日期：2026-11-15。所属：[底层架构综合方案](2026-11-12-foundation-omui-xengine-emergent-world-design.md) M6.4 的验收作品（§12 表中“与参照物同等内容的 FPS 纵切”）。状态：设计，逐检查点落地。

## 1. 是什么

**Quay** 是一款原创的第一人称射击小品：雨夜的港口，守夜人要在潮水退去前点亮防波堤尽头的信号灯；集装箱之间巡逻着锈蚀的看守机（warden），它们靠**听**和**看**找人。场景沿用 M6.3 的里程碑画面（雨夜港口：湿地面、多光源阴影、雾、泛光），玩法、角色、关卡、美术与声音全部是本项目自己的。

参照物只用来对照**内容规模**（§1 表：浏览器 FPS，PBR、阴影、雾、实例化、蒙皮、雨与湿地面、贴花、泛光与色调映射、程序化声音），不复刻它的名字、关卡、美术、声音或外观。

验收（方案 §12）：可玩、可回放；Agent 玩家在人类档通关；适配器过契约 CTS（或如实列出不支持项）；记录制作成本，与参照物公开的数字并列。

## 2. 三级次序（D-185）

| 级 | 试了什么 | 结论 |
|---|---|---|
| ① 原始性创新 | **一条感知通路**：看守机、Agent 玩家和人听到、看到的是同一份数据——`xengine.audio.space` 的 `heard()`（到达双耳的实测电平、方位、穿过几面墙）与射线可见性。看守机不读游戏状态里“玩家在哪”，只读它听到和看到的；Agent 玩家在人类档也只拿这些。**世界是值**：每一帧可分叉，Agent 在分叉上试打再决定。**每次命中有因果**：一发子弹从扳机到看守机倒下的链条可查询 | 采用：这是本体系独有的（一棵语义树多种渲染、世界是值、因果记录、Agent 在架构底层），同类引擎的 FPS 模板里 AI 直接读玩家位置 |
| ② 前沿组合 | 物质规律进玩法：照明弹是带物质的粒子（`xengine.particles`），点燃信号灯的木柴靠物质规律；看守机的金属被击中溅出铁火花并按规律冷却；空间声音的多普勒与双耳时差来自同一条传播规则 | 采用，按检查点逐步接入 |
| ③ 业界顶尖做法 | 标准 FPS 循环：角色控制器（Jolt CharacterVirtual）、命中扫描、寻路人群（Detour）、蒙皮动画（ACL 压缩的姿态通道）、粒子、泛光与色调映射 | 作为低线，全部经已落地的适配器 |

## 3. 架构（只消费公开能力，D-63）

```
showcase/quay/
  sim       世界与规则：港口的静态几何与可推动的货箱（xengine.dynamics.rigid3）、守夜人（角色控制器）、
            看守机（xengine.nav 的人群 + 小状态机）、武器（命中扫描）、照明弹（xengine.particles）、
            潮水计时、胜负；状态是值（mlibs.simulation::Branching 包着 Jolt 与 Detour 的世界）
  headless  xengine.runtime 的 Playable；Agent 玩家：人类档只给 heard() 与视野内可见的东西
  picture   xrender.mesh（港口、雨、湿地面、雾、泛光）+ hanim.skeleton 的蒙皮看守机 + xrender.particle
  sound     xengine.audio.space：枪声、脚步、撞击、看守机的伺服声，从世界的事件生成
  play      SDL3 窗口、指针锁定（omui 视口节点）
```

依赖只向下：作品 → xengine/game → omui → 内核。sim 不依赖渲染与声音；picture、sound 只读状态。

## 4. 检查点

| # | 内容 | 验收 |
|---|---|---|
| F1 | sim：港口与货箱、守夜人的移动与视角、命中扫描、看守机巡逻→听到→追→开火、生命、潮水计时、信号灯；`Branching` 让 Jolt 与 Detour 的世界成为值 | 同一输入同一哈希；拷贝即分叉；脚本玩家通关；看守机只凭 `heard()` 与视线找到玩家（关掉声音它就找不到） |
| F2 | headless：Playable、Agent 玩家（人类档：视野与听觉；完整档：加哈希） | Agent 在人类档通关；分叉试打；关卡里预埋的问题被找出并说明原因 |
| F3 | picture：港口、蒙皮看守机、枪口火花与雨、贴花（弹孔）、泛光 | 无头出图；CPU 参考与设备一致（lavapipe、RTX 4080）；帧预算按 D-187 实测 |
| F4 | sound：空间声音接到世界事件 | 枪声在右侧时右耳先到更响；穿墙变暗；离线渲染逐位一致 |
| F5 | play：窗口与指针锁定 | 人可以玩；回放文件逐位重现 |
| F6 | 并排对照与成本记录 | 与参照物逐项并排（落后／持平／领先，D-135）；时长、检查点数、人介入次数 |
