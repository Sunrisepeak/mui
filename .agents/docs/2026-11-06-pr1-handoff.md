**本轮实际交付。** `hanim::anim::follow_path(object, path, options)` 已接入公共 `import hanim`，复用现有 MotionPath 距离求值和属性通道。默认相对实际阶段源放置，可选根／命名部件；闭合曲线起终点相同时，中间过程仍真实运动。可与独立旋转、缩放、repeat／sequence 和图像 scope 组合。`TranslationRoute` 冻结拥有路径副本，调用方后续编辑不影响已有描述，重复引用可廉价共享。没有新增 mcpp 子项目、播放器、网页采样器或强制 UI／renderer 依赖。

准备时拒绝空、非有限或不连续路径；连续零长度路径允许静止。position／offset／route 互斥。单段和组合路径属性一致拒绝不支持的几何变形 modifier，translation PointPath 与图像效果保持各自语义。路径新增有效性／连续性／段数查询；位置查询复用已有查表，不计算不需要的切线角。

`MorphOptions::max_route_segments`、`ProgramLimits::max_total_route_segments`、`EngineLimits::max_total_route_segments` 分层限额；prepared object／program 提供 `route_segment_count()`。按逻辑保留使用计数，不是唯一内存字节；共享不可变路径不能绕过预算。播放失败不部分发布，重定向替换和 release 的账目已验证。Program contract 为 **8**；旧枚举值保留，C++ Modules 消费者重建。

官网 `#/motion/component-motion` 的详情新增“曲线环游”：真实便笺沿两个闭合曲线段运动，标题 wobble、按钮 pulse 独立，仍可选择图像效果／局部风格、编辑内容、点击复制。复制的 C++ 是相同公开 API。既有 `motion.seek` 驱动同一实例，支持人操作与 Agent 无窗口过程审查。
