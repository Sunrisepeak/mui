# omui-cli operations

The project's commands: create, build, test, check, describe, package; dependencies, tools and the design's history.

Generated by `ops-gen` from the catalog; the effect is openas's.

| Operation | Effect | Parameters | Result | Cost | Undo | Cancel |
|---|---|---|---|---|---|---|
| `omui.doctor` — Which tools are there and which are missing, and the project's health: the general rules, the workspace's and omui's profiles (an app, an extension), each finding with its fix | read | `dir`: path (optional) | json | bounded | — | no |
| `omui.templates` — The templates a project is made from, and what each makes | read | — | json | instant | — | no |
| `omui.new` — A new project from a template (app-ts by default): a directory of files, written beside the one the server runs in | irreversible | `name`: string, `template`: string (optional) | json | heavy | none: delete the directory it made | no |
| `omui.build` — Builds the project (mcpp build): its outputs under target/, nothing else changed | reversible | `release`: bool (optional), `web`: bool (optional), `lang`: string (optional), `look`: bool (optional), `rest`: json (optional) | json | heavy | none needed: target/ is the build's own | no |
| `omui.test` — Runs the project's tests (mtest): which passed, which failed and where | reversible | `rest`: json (optional) | json | heavy | none needed: tests change nothing they keep | no |
| `omui.dev` — Runs the application in development mode: it is its own designer, a person and an agent design it live (D-149); an application in C++ runs in the development host, rebuilt as its sources change (W16) | reversible | `headless`: bool (optional), `rest`: json (optional) | json | heavy | none needed: it ends when stopped | no |
| `omui.run` — Runs the application as it ships (mcpp run); after --, its own switches: --headless, --png FILE, --serve … | reversible | `release`: bool (optional), `rest`: json (optional) | json | heavy | none needed: it ends when stopped | no |
| `omui.connect` — Starts the bridge a page in your browser pairs with, so an agent operates it with `omui page …` (it runs until stopped) | reversible | `code`: string, `port`: integer (optional), `name`: string (optional), `origin`: string (optional), `dir`: path (optional) | json | heavy | none needed: it ends when stopped | no |
| `omui.mcp` — An MCP server on standard input and output: agents operate running applications with ui_* tools, and the project's commands | reversible | `app`: string (optional), `actor`: string (optional), `way`: string (optional), `tools`: string (optional), `ops`: json (optional), `dir`: path (optional) | json | heavy | none needed: it ends when its input does | no |
| `omui.replay` — Plays a recording (the protocol's `record`, development mode) in a fresh instance, headless, and checks it ends as it did: the semantic tree's hash and the pixels' (W12) | reversible | `file`: path | json | heavy | none needed: a replay keeps nothing | no |
| `omui.check` — Type-checks the project's TypeScript against the API it registers (tsc), or view documents: each problem at its line | read | `files`: json (optional), `portable`: bool (optional) | json | heavy | — | no |
| `omui.describe` — What writing for the project takes: every builder, native module, theme token and verb, as JSON | read | `llms`: path (optional) | json | heavy | — | no |
| `omui.fmt` — View documents written in the canonical format; with check, only which are not | reversible | `files`: json, `check`: bool (optional) | json | bounded | the files as they were (version control) | no |
| `omui.schema` — The JSON Schema of view documents over the official components (written to out when given) | reversible | `out`: path (optional) | json | bounded | delete the file written | no |
| `omui.deps` — The project's dependencies as its mcpp.toml declares them | read | — | json | instant | — | no |
| `omui.tools` — The tools the project names for xlings, and whether each is installed | read | — | json | bounded | — | no |
| `omui.tools.install` — Installs the tools the project names (xlings install) | irreversible | — | json | heavy | none: xlings remove what it installed | no |
| `omui.config` — The project's omui.config.ts over the defaults: how far agents may go, what the recorder keeps, whether the designer is linked | read | — | json | bounded | — | no |
| `omui.add` — Adds a dependency to mcpp.toml (mcpp add) | reversible | `package`: string | json | bounded | omui.remove | no |
| `omui.remove` — Removes a dependency from mcpp.toml (mcpp remove) | reversible | `package`: string | json | bounded | omui.add | no |
| `omui.package` — Packages the application for people to install (mcpp pack): an artifact written to keep and hand out | irreversible | `format`: string (optional) | json | heavy | none: delete the package it wrote | no |
| `omui.design.sync` — Carries Live Design's history into git: each design commit a commit on design/<branch>, tags as design/<tag> (the work tree untouched) | irreversible | `dir`: path (optional) | json | bounded | none: delete the design/* references | no |
| `omui.design.film` — The design's history as a film (WebM): each step as it was presented, captioned | irreversible | `out`: path (optional), `branch`: string (optional), `fps`: integer (optional), `seconds`: number (optional) | json | heavy | none: delete the film | no |
