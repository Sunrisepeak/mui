# omui operations

Read, find, act on, wait for, capture and inspect a running application's semantic tree.

Generated by `omui-gen ops` from the catalog; the effect is openas's.

| Operation | Effect | Parameters | Result | Cost | Undo | Cancel |
|---|---|---|---|---|---|---|
| `ui.describe` — What this endpoint is: the protocol, the application, its operations, the session's policy and the application's verbs | read | — | json | instant | — | no |
| `ui.snapshot` — The semantic tree, or a part of it | read | `root`: node (optional), `depth`: integer (optional), `interactive`: bool (optional), `offset`: integer (optional), `limit`: integer (optional), `children_limit`: integer (optional) | tree | bounded | — | no |
| `ui.changes` — What changed in the tree since the last snapshot or changes | read | — | json | instant | — | no |
| `ui.find` — Nodes matching a query (role, name, id, state; wildcards) | read | `q`: json | json | bounded | — | no |
| `ui.act` — Perform a node's action, under that action's effect (an irreversible one asks the person) | at most irreversible, as what it runs | `node`: node, `action`: string, `args`: json (optional), `answer`: string (optional), `dry_run`: bool (optional) | json | frame | the action's own: ui.undo for a reversible one; an irreversible one cannot be taken back | no |
| `ui.invoke` — Call one of the application's verbs, under its declared effect | at most irreversible, as what it runs | `verb`: string, `args`: json (optional), `answer`: string (optional), `dry_run`: bool (optional) | json | bounded | the verb's own (an undoable verb: ui.undo) | no |
| `ui.undo` — Take back the last change in a history scope | reversible | `scope`: node (optional) | json | instant | ui.redo | no |
| `ui.redo` — Do again what ui.undo took back | reversible | `scope`: node (optional) | json | instant | ui.undo | no |
| `ui.transaction` — Steps performed as one: all done, or all taken back | reversible | `steps`: json, `label`: string (optional) | json | bounded | ui.undo takes the whole transaction back | no |
| `ui.preview` — What steps would make, shown before it is allowed: pictures before and after, the semantic changes; nothing stays | read | `steps`: json, `pictures`: bool (optional) | json | bounded | — | no |
| `ui.history` — A history scope's changes, what can be undone and redone | read | `scope`: node (optional) | json | instant | — | no |
| `ui.wait` — Answer when a condition holds: a node present or absent, the tree settled | read | `q`: json (optional), `absent`: json (optional), `settled`: bool (optional), `timeout`: seconds (optional) | json | heavy | — | no |
| `ui.capture` — The picture as drawn: the window, a node, or a region of it, as PNG pixels or as SVG with every node's drawing marked | read | `node`: node (optional), `region`: json (optional), `format`: string (optional) | image | frame | — | no |
| `ui.input` — A person's input as their devices give it (pointer, keys, text), delivered a frame at a time; answers what each press hit | reversible | `events`: json | json | heavy | what the input performed is the actions' own (ui.undo for reversible ones) | no |
| `ui.intend` — Say to the person what you are about to do (the steps, or a note) — or, handing the task back, what you did, what is left, what you were unsure of: shown by your presence until you say another; nothing in the application changes | read | `text`: string, `node`: string (optional), `hands_back`: bool (optional) | json | instant | — | no |
| `ui.timeline` — What input did, oldest first: each input event's records — what it hit, what stopped it (disabled, outside, nothing to press, refused), what it activated — at the recorder's level | read | `since`: integer (optional), `limit`: integer (optional) | json | instant | — | no |
| `ui.explain` — A press and what came of it, from press to release: what it hit, what stopped it, the actions it led to, and a sentence saying what happened | read | `at`: json (optional), `cause`: integer (optional) | json | instant | — | no |
| `ui.drew` — What drew a pixel: the node its colour came from, the nodes it sits in, and where in the program each was built | read | `at`: json | json | instant | — | no |
| `ui.inspect` — A node's layout, style, state, bindings and motion, for development | read | `node`: node (optional) | json | instant | — | no |
| `ui.stats` — Frame times (mean, percentiles, phases) and the last frame's counts | read | `history`: integer (optional) | json | instant | — | no |
| `ui.profile` — Start or stop recording a trace; stopping answers its summary (and Chrome's format) | reversible | `action`: string, `chrome`: bool (optional) | json | instant | the other action | no |
| `ui.logs` — Recent log records, by level and category | read | `level`: string (optional), `category`: string (optional), `limit`: integer (optional) | json | instant | — | no |
| `ui.debug` — Debug overlays (bounds, repaints, inspector, HUD), the slow-frame threshold and the log filter | reversible | `bounds`: bool (optional), `repaints`: bool (optional), `inspector`: bool (optional), `hud`: bool (optional), `slow_frame_ms`: number (optional), `log`: string (optional) | json | instant | ui.debug with the values it answered before | no |
| `ui.pipeline` — The frame's pipeline: show it (a read), or replace, insert or remove one stage between frames | reversible | `action`: string (optional), `stage`: string (optional), `plugin`: string (optional), `after`: json (optional), `config`: json (optional) | json | instant | the opposite change: the stage as show read it | no |
| `ui.clock` — The application's time: show it (a read), or pause, resume, rate, step, seek and release | reversible | `action`: string (optional), `rate`: number (optional), `seconds`: seconds (optional) | json | instant | release gives the time back to the host | no |
