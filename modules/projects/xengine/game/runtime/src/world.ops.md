# world operations

Observe a game running on its own, play it as a person does, step and seek its time, and ask what would be.

Generated by `omui-gen ops` from the catalog; the effect is openas's.

| Operation | Effect | Parameters | Result | Cost | Undo | Cancel |
|---|---|---|---|---|---|---|
| `world.observe` — What a player on this tier is shown at this frame, with the frame and the state's hash | read | — | json | instant | — | no |
| `world.state` — The frame, the state's hash, whether the game is over, and the frames it can be sought within | read | — | json | instant | — | no |
| `world.act` — A player's actions, as a person's: the state shows them from `effective`, no sooner than the tier's reaction after `seen`, and they hold until the next | reversible | `seen`: integer (optional), `buttons`: json (optional), `axis`: json (optional), `pointer`: json in plane (optional) | json | instant | world.seek to the frame before it took effect | no |
| `world.step` — Plays steps; only where the agent steps the game (an owner's clock refuses it) | reversible | `steps`: integer (optional) | json | bounded | world.seek to the frame it began at | no |
| `world.seek` — Returns to a frame within the history kept; what is played from there is a new branch | reversible | `frame`: integer | json | bounded | none within the runtime: what came after the frame is another branch's | no |
| `world.branch` — What would be: the future's view and hash some steps ahead holding given actions; the game itself untouched | read | `steps`: integer (optional), `buttons`: json (optional), `axis`: json (optional), `pointer`: json in plane (optional) | json | bounded | — | no |

## Agent player tiers

| Tier | Shown | Reaction | Actions a second | Operations |
|---|---|---|---|---|
| `human` — As a person plays: shown what is drawn, a tenth of a second's reaction, ten actions a second. | what is drawn | 100 ms | 10 | `world.observe`, `world.state`, `world.act`, `world.step`, `world.seek`, `world.branch` |
| `assist` — Privileged: shown everything, no reaction time, no limit. | everything | 0 ms | no limit | `world.observe`, `world.state`, `world.act`, `world.step`, `world.seek`, `world.branch` |
