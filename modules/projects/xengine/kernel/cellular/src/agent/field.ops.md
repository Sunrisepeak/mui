# field operations

Read a field of cells as numbers, place values in it, step it, return to a frame, ask what would be, and who changed a cell.

Generated by `omui-gen ops` from the catalog; the effect is openas's.

| Operation | Effect | Parameters | Result | Cost | Undo | Cancel |
|---|---|---|---|---|---|---|
| `field.observe` — The frame, the steps run, the state's hash, the field's shape, and each channel of a region as numbers: least, most, sum, cells not zero | read | `region`: json in lattice-2d (optional), `budget`: integer (optional) | json | bounded | — | no |
| `field.cells` — One channel's values in a region, row by row; at most 4096 cells a request | read | `channel`: integer, `region`: json in lattice-2d | json | bounded | — | no |
| `field.place` — Sets one channel to a value over a region; a frame of its own, recorded like a step | reversible | `channel`: integer, `value`: integer, `region`: json in lattice-2d | json | bounded | field.seek to the frame before it | no |
| `field.step` — Runs the program a number of steps over the field: the tiles awake (what is at rest sleeps, the result the same); answers where the field is and how many of its tiles sleep | reversible | `steps`: integer (optional) | json | bounded | field.seek to the frame it began at | no |
| `field.seek` — Returns to a frame within the history kept; what is run from there is a new branch | reversible | `frame`: integer | json | bounded | none within the field: what came after the frame is another branch's | no |
| `field.branch` — What would be: the field some steps ahead, a value placed first when one is given, observed as field.observe does; the field itself untouched | read | `steps`: integer (optional), `channel`: integer (optional), `value`: integer (optional), `place`: json in lattice-2d (optional), `region`: json in lattice-2d (optional) | json | bounded | — | no |
| `field.explain` — Why a cell holds what it holds, as far as the field knows: its values, the edits on record that cover it — what was written, at which frame, by whom — the latest first, and what the program changed of it in the last step | read | `cell`: json in lattice-2d | json | bounded | — | no |

## Tasks to begin with

Each step is a request as it is sent; `describe` gives the same to an agent.

**read-the-field** — Read the field's channels in brief, then one channel's cells in a region

```json
{"op":"field.observe"}
{"op":"field.cells","channel":0,"region":[0,0,4,4]}
```

**place-step-and-look** — Place a value, step the rules, and read what became of it

```json
{"op":"field.place","channel":0,"value":1,"region":[9,0,1,3]}
{"op":"field.step","steps":5}
{"op":"field.observe"}
```

**ask-what-would-be** — See the field some steps ahead with a value placed first, the field itself untouched

```json
{"op":"field.branch","steps":8,"channel":0,"value":1,"place":[0,0,16,1]}
```

**ask-who-changed-a-cell** — Place a value and ask who changed a cell, and what the last step did to it

```json
{"op":"field.place","channel":0,"value":1,"region":[10,3,3,1]}
{"op":"field.explain","cell":[11,3]}
```
