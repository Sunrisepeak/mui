# 组件质感细节清单（B4–B6）

2026-11-08。[官网重构与 Mui 方案](2026-11-08-site-redesign-mui-design.md) §3.4 要求的逐组件细节清单。每条对应 §3.1–§3.3 的一项规范，落在**框架**（主题令牌、默认动效规则、组件本身），不落在官网。状态：✓ 已完成（默认），○ 待做。

## 0. 做法

- 新的取值先进一个暂存叠加层，框架默认和所有钉住值不动；对照图经人工批准（第一组的对照图见 [media/2026-11-08-quality/controls.png](media/2026-11-08-quality/controls.png)：左四列旧默认、右四列新取值）。
- 批准后在**一个检查点**里并入 `light`／`dark`，删除叠加层，同时更新钉住值。第一组已于 2026-11-08 批准并入；深色主题的阴影单独调色（黑色、更强），不是浅色的反转。
- 审查图：`site/tests/quality_lab_test.cpp`（scratch `quality-lab/controls.png`）每个控件静止、悬停、按下、键盘焦点四态，浅色与深色并排；并入后的样子见 [media/2026-11-08-quality/controls-defaults.png](media/2026-11-08-quality/controls-defaults.png)。
- 组件不写死质感数值：圆角平滑由框架统一套到组件自己画的形状上（`DisplayList::smooth_corners`）；深度来自阴影令牌（`parts::depth`：`<令牌>`、`<令牌>:hovered`、`<令牌>:pressed`）；阴影可以带投射物的颜色（`tint`）。

### 1.1 第一组第二遍（2026-11-09 暂存；2026-11-16 并入默认，RC2.17）

与 Material 3 并排盲比（compare-v1，D-135）发现：开关、勾选框、滑块的静止、悬停、按下三态几乎一样。新的取值先暂存在 `refined` 叠加层；按收敛方案 RC2.17（组件质感清单并入默认）于 2026-11-16 并入 `light`（`dark` 继承，光晕取控件自身颜色），叠加层删除，钉住值同时更新。对照图：[media/2026-11-09-quality/controls-halo.png](media/2026-11-09-quality/controls-halo.png)（左四列现在的默认，右四列 refined）。

| 组件 | 细节 | 令牌 | 状态 |
|---|---|---|---|
| 开关 | 悬停、按下时拇指周围的状态光晕，取轨道的颜色；按下更大、更深 | `switch_halo:hovered`／`:pressed` | ✓ |
| 开关 | 按下时拇指沿行进方向拉长 6 px（开：向左；关：向右） | `spacing.switch_press_stretch` | ✓ |
| 勾选框 | 悬停、按下时方框外的圆形状态光晕（强调色） | `check_halo:hovered`／`:pressed` | ✓ |
| 滑块 | 光晕改由令牌给出（原来写死在组件里）；键盘焦点改为拇指外的焦点环，与悬停、按下的光晕分开 | `thumb_halo:hovered`／`:pressed` | ✓ |

盲比结果（每张图 3 个新会话，取多数）：勾选框、滑块领先 Material 3；开关仍落后（3 票中 1 领先、2 落后，置信度低），理由是悬停与按下仍不够分明、轨道相对标签偏小。开关的比例另做一遍（○）。
