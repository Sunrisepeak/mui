# omui identity and page renders

Generated by `mcpp test -p openmui.site`: `tests/brand_test.cpp` draws these with the framework's CPU renderer, using the geometry in `src/brand.cpp`. The SVG originals use the same paths and have no font or image dependencies.

- `mark-light.png`, `mark-dark.png`: 16, 24, 32, 64 and 256 px size sheets.
- `mark-light.svg`, `mark-dark.svg`: the same geometry as standalone vector originals.
- `study-assembled.png`, `study-unfolded.png`: the live construction study at 1280×800.
- `study-phone.png`: the Chinese study at 390×844.

Regenerate with `tools/ci/readme-media.sh site`; after testing, verify with `tools/ci/readme-media.sh --check site`. Review the rendered images before committing changed media.

`structure-*.png` are generated by the viewport test in `tests/site_test.cpp`: Home, Docs, Explore and Get started at 1280×800, plus the Chinese documentation overview and reading page at 390×844. They show the current page responsibilities and navigation; the later galleries and final art direction remain in the redesign plan. The media check also compares these six images with the test outputs.
