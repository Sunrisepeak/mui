# field operations

Read a field of cells as numbers, place values in it, step it, return to a frame, ask what would be, and who changed a cell.

Generated by `omui-gen ops` from the catalog; the effect is openas's.

| Operation | Effect | Parameters | Result | Cost | Undo | Cancel |
|---|---|---|---|---|---|---|
| `field.observe` — The frame, the steps run, the state's hash, the field's shape, and each channel of a region as numbers: least, most, sum, cells not zero | read | `region`: json (optional), `budget`: integer (optional) | json | bounded | — | no |
| `field.cells` — One channel's values in a region, row by row; at most 4096 cells a request | read | `channel`: integer, `region`: json | json | bounded | — | no |
| `field.place` — Sets one channel to a value over a region; a frame of its own, recorded like a step | reversible | `channel`: integer, `value`: integer, `region`: json | json | bounded | field.seek to the frame before it | no |
| `field.step` — Runs the program a number of steps over the field: the tiles awake (what is at rest sleeps, the result the same); answers where the field is and how many of its tiles sleep | reversible | `steps`: integer (optional) | json | bounded | field.seek to the frame it began at | no |
| `field.seek` — Returns to a frame within the history kept; what is run from there is a new branch | reversible | `frame`: integer | json | bounded | none within the field: what came after the frame is another branch's | no |
| `field.branch` — What would be: the field some steps ahead, a value placed first when one is given, observed as field.observe does; the field itself untouched | read | `steps`: integer (optional), `channel`: integer (optional), `value`: integer (optional), `place`: json (optional), `region`: json (optional) | json | bounded | — | no |
| `field.explain` — Why a cell holds what it holds, as far as the field knows: its values, the edits on record that cover it — what was written, at which frame, by whom — the latest first, and what the program changed of it in the last step | read | `cell`: json | json | bounded | — | no |
