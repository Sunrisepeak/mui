# lab operations

Design matter: change a material's row or a law and see the same scene under the new definition, try a change before making it, keep every step as a commit, and hold the part you are working on. The scene is its edits — what was placed and applied, each at its step: a change of the definition plays it again to its last edit, and steps run on after that are the running world's, not the scene's.

Generated by `omui-gen ops` from the catalog; the effect is openas's.

| Operation | Effect | Parameters | Result | Cost | Undo | Cancel |
|---|---|---|---|---|---|---|
| `lab.describe` — What is being designed: each source with its lines and hash — a material a file (materials/wood.json), the laws (laws.json), the look (look.json), the scene (scene.json) — the world's shape and steps, the commit shown, whether there are changes not committed, and the claims held | read | `budget`: integer (optional) | json | instant | — | no |
| `lab.read` — One source's text as it is now | read | `path`: string | json | bounded | — | no |
| `lab.edit` — One source's text replaced, made or removed: the definition is prepared, the look checked and the scene played again under them, to the same step, before anything is replaced — a text with a problem changes nothing and says where. Answers what changed in the world (cells that differ, materials then and now) and its commit | reversible | `path`: string, `text`: string (optional), `remove`: boolean (optional), `intent`: string (optional) | json | bounded | lab.revert to the commit before it (`HEAD~1`) | no |
| `lab.material` — One material's row: made when it is not there, properties set (null takes one away) or the row removed — its own source changed and nothing else, the scene played again. Answers as lab.edit | reversible | `name`: string, `properties`: json (optional), `remove`: boolean (optional), `intent`: string (optional) | json | bounded | lab.revert to the commit before it (`HEAD~1`) | no |
| `lab.law` — One law by its name: replaced where it stands, added after the last when it is new, or removed. A law reads properties and never a material's name (refused otherwise). Answers as lab.edit | reversible | `name`: string, `law`: json (optional), `remove`: boolean (optional), `intent`: string (optional) | json | bounded | lab.revert to the commit before it (`HEAD~1`) | no |
| `lab.try` — What a change would do, nothing changed: the same scene played under the changed sources and under these, some steps on — cells that differ, materials in each, what happened in each counted by name | read | `material`: string (optional), `properties`: json (optional), `path`: string (optional), `text`: string (optional), `steps`: integer (optional) | json | bounded | — | no |
| `lab.reset` — The scene begun anew: a field of a shape filled with one material, nothing placed, no step run. Answers as lab.edit | reversible | `shape`: json (optional), `filled`: string (optional), `intent`: string (optional) | json | bounded | lab.revert to the commit before it (`HEAD~1`) | no |
| `lab.explain` — Why a part of the design is what it is: the commits that changed its source, newest first — who, what for, the lines before and after — and who holds it now. With a property: the line that says it and the commit that last wrote that line | read | `part`: string, `property`: string (optional), `limit`: integer (optional) | json | bounded | — | no |
| `lab.picture` — The field as it looks now — every cell by the look, its light as a glow — as a PNG kept beside the lab by its content: its path, size and hash | read | `scale`: integer (optional) | json | bounded | — | no |
| `lab.history` — The design's history: the branch worked on, branches and tags, a branch's commits newest first — each with who made it — and whether what runs has changes not committed | read | `branch`: string (optional), `limit`: integer (optional) | json | bounded | — | no |
| `lab.commit` — What runs now kept as a commit on the branch worked on, with its picture (a change of the definition keeps itself; this keeps what was placed in the scene since) | reversible | `message`: string | json | bounded | lab.revert to the commit before it (`HEAD~1`) | no |
| `lab.branch` — A branch made at a commit (the one worked on when none is given); work stays where it is | reversible | `name`: string, `at`: string (optional) | json | instant | a branch is left behind by switching away; nothing is lost | no |
| `lab.switch` — Another branch's, tag's or commit's sources put into what runs: its definition prepared, its scene played; refused while there are changes not committed, unless forced | reversible | `to`: string, `force`: boolean (optional) | json | bounded | lab.switch back | no |
| `lab.revert` — A commit's sources put back as a new commit: nothing of the history is lost | reversible | `to`: string | json | bounded | lab.revert to the commit before it (`HEAD~1`) | no |
| `lab.diff` — Where two states differ, by source and line: a commit against another, or against what runs now | read | `from`: string (optional), `to`: string (optional) | json | bounded | — | no |
| `lab.merge` — Another branch's changes brought into this one, by source and by line: two materials added on two branches are both there, two properties of one material both set; the same line changed on both merges nothing and says which sources. The merged definition is prepared and played before it is kept | reversible | `from`: string | json | bounded | lab.revert to the commit before it (`HEAD~1`) | no |
| `lab.tag` — A name given to a commit (the one worked on when none is given) | reversible | `name`: string, `at`: string (optional) | json | instant | a tag stays; give another name | no |
| `lab.claim` — A part held while working on it: others' changes to it wait and are told who holds it and what for (a person is never held). A lease: asked again, it is renewed | reversible | `part`: string, `intent`: string (optional), `subtree`: boolean (optional), `seconds`: number (optional) | json | instant | lab.release | no |
| `lab.release` — A part let go (a person lets go of anyone's) | reversible | `part`: string | json | instant | lab.claim again | no |
| `lab.claims` — The parts held now: who, what for, how long yet | read | — | json | instant | — | no |

## Tasks to begin with

Each step is a request as it is sent; `describe` gives the same to an agent.

**read-the-definition** — Read what the definition is made of, then one material's row

```json
{"op":"lab.describe"}
{"op":"lab.read","path":"materials/wood.json"}
```

**try-before-changing** — See the same scene under a changed row, beside the scene as it is, nothing changed

```json
{"op":"lab.try","material":"wood","properties":{"ignition":5000},"steps":40}
```

**change-a-material-and-ask-why** — Change a property of a material, see the commit it made, and ask who set the property and why

```json
{"op":"lab.material","name":"wood","properties":{"ignition":600},"intent":"wood lights sooner"}
{"op":"lab.history","limit":3}
{"op":"lab.explain","part":"materials/wood","property":"ignition"}
```

**take-a-change-back** — Make a change, compare it with the commit before, and go back to that commit

```json
{"op":"lab.material","name":"wood","properties":{"ignition":600},"intent":"wood lights sooner"}
{"op":"lab.diff","from":"HEAD~1"}
{"op":"lab.revert","to":"HEAD~1"}
```

**hold-the-part-you-work-on** — Say which part you are working on so others do not write over it, and let it go

```json
{"op":"lab.claim","part":"materials/wood","intent":"tuning how wood burns"}
{"op":"lab.claims"}
{"op":"lab.release","part":"materials/wood"}
```
