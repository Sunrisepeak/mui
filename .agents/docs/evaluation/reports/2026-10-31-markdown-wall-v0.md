2. **Redesign semantic zoom:** readable document titles at overview scale, useful summaries at medium scale, full typography at reading scale.
3. **Make work durable:** save arrangements, camera and task changes; retain document scroll/state across tier transitions.
4. **Replace fixed-gap packing:** fit workspace bounds to the viewport, reduce the central void, and measure preview content heights.
5. **Finish window chrome:** clear focus/selection/drag states, title/path truncation rules, readable controls and consistent elevation.
6. **Close performance acceptance gaps:** uninterrupted mixed live/texture workloads, integrated-GPU results, peak-memory limits and zero-allocation steady frames.
7. **Replace the duplicate still evidence:** capture a deterministic useful workflow, representative Markdown close-ups, all tiers and updated benchmark documentation.
