# body operations

Read a soft body's place, squash, speed and contacts, push it, step it, return to a frame, and ask what would be.

Generated by `omui-gen ops` from the catalog; the effect is openas's.

| Operation | Effect | Parameters | Result | Cost | Undo | Cancel |
|---|---|---|---|---|---|---|
| `body.observe` — The frame, the state's hash, the body's centre, bounds, area against its rest area, its fastest particle's speed, and what it touches | read | `budget`: integer (optional) | json | instant | — | no |
| `body.particles` — Each particle's place and velocity, in order around the ring | read | — | json | bounded | — | no |
| `body.push` — What acts on the body from the next step on, held until the next push: a force on the whole of it, a walk along what it stands on; and once, on the next step alone, a kick | reversible | `force`: json (optional), `walk`: number (optional), `kick`: json (optional) | json | instant | body.seek to the frame before it took effect | no |
| `body.step` — Steps the body under what is held | reversible | `steps`: integer (optional) | json | bounded | body.seek to the frame it began at | no |
| `body.seek` — Returns to a frame within the history kept; what is stepped from there is a new branch | reversible | `frame`: integer | json | bounded | none within the body: what came after the frame is another branch's | no |
| `body.branch` — What would be: the body some steps ahead under a given push, observed as body.observe does; the body itself untouched | read | `steps`: integer (optional), `force`: json (optional), `walk`: number (optional), `kick`: json (optional) | json | bounded | — | no |
| `body.contacts` — What the last step touched, in words: its place, its squash, its speed, its contacts by kind, and the stages a step goes through | read | — | string | instant | — | no |
