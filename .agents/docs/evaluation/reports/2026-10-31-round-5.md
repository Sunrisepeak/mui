## 用出来的问题和处理

| 问题（对象） | 处理 |
|---|---|
| agent 的输入点击“导出”这类外部动作，被当成了人的确认（style-gallery） | agent 的输入不替人回答：有输入 actor 时，点击外部动作一律要人的答复。有测试 |
| 减少透明时，组件自己画的部分仍然透明（style-gallery） | 主题本身变实心：半透明的表面色按它叠在背景上的样子算成不透明，焦点、选区、遮罩和阴影不变；每个作用域各有一份，主题、作用域或这个设置变化时重算。有测试 |
| 玻璃标签栏悬停时变成一块白板（style-gallery） | 悬停保留颜色本身的透明度，选中的标签不再叠一层悬停；开关的边框同样处理 |
| 文档还在平滑滚动，`wait settled` 已经返回（ui-framework） | 新增 `Services::moving`：组件在绘制时声明自己的动画正在进行，这个节点对所有读者都处于 animating，直到某次绘制不再声明为止。滚动视图和 base 的 `keep_frames` 都会声明。有测试 |
| 事务失败后，计数器的 +1 还留着，回答却说已经全部撤回（ui-framework） | 无法尝试的步骤：预演结果为 fail；预演显示无法撤回的步骤：事先拒绝整个事务；确实留下的步骤：按名字说明。MCP 不再一律说“nothing of it stays”。有测试 |
| 示例 08 的目录栏被挤到 29 px（ui-framework） | 目录栏保持宽度，文档区改为滚动。有测试 |

## 排进下一轮的

- **原生无障碍**：框架整体分卡在这一项。计划沿用 D-21：通过 mwrap 接入 AccessKit 的 C 绑定，对接 UIA、NSAccessibility 和 AT-SPI。
- **渲染**：与 Skia、Blend2D、Vello 对照的正确性和性能基准；小字号 CJK 等参考图。
- **动画**：属性、关键帧和曲线的编辑；可复用的绑定和权重；自动布局动画。
- **引擎**：
  - 存档要连同 CPU、训练假人和回合状态一起保存，否则拒绝存档；
  - 收到完整数据包再修改状态；
  - 一局真正的联网对战，带同步诊断。
- **格斗游戏**：按 D-90 继续推进霓的试点。
