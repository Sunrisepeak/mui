# oweb operations

A site states its title, address, languages, routes and budget in its oweb.config.ts; every operation reads it and a request's options stand over it. Build a directory of pages into a site whose every route is its semantic tree written as HTML and as Markdown; list a site's routes; read one page as an agent that only fetches would, and search every page's sections, without building the site.

Generated by `ops-gen` from the catalog; the effect is openas's.

| Operation | Effect | Parameters | Result | Cost | Undo | Cancel |
|---|---|---|---|---|---|---|
| `site.build` — Build the site: each page of pages/ a route with its index.html (the tree as HTML: readable with no script) and index.md (the tree as Markdown), the routes table, llms.txt, the search index, given the site's address sitemap.xml, and the delivery manifest — every file as stored and as a static host sends it, each route's bytes before it reads held to a budget (over it: written, and failed with where). A link inside the site that leads nowhere fails the build with each one said, and nothing is written | reversible | `site`: path, `out`: path, `title`: string (optional), `languages`: string (optional), `url`: string (optional), `readable`: string (optional) | json | bounded | delete the directory written | no |
| `routes.list` — The routes a site's pages give: each its address, source, title, language and headings with their anchors | read | `site`: path, `languages`: string (optional) | json | instant | — | no |
| `page.read` — One route as it would be written, without building the site: its Markdown (what an agent that only fetches reads) or its HTML | read | `site`: path, `route`: string, `as`: string (optional), `languages`: string (optional) | json | bounded | — | no |
| `docs.search` — The sections of a site's pages that hold every word asked for, best first: each its route, its anchor, the headings it is under and the line that says so — the same index a built site serves as site.search.xdef.json | read | `site`: path, `query`: string, `limit`: string (optional), `languages`: string (optional) | json | bounded | — | no |
