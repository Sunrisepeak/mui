# oweb operations

Build a directory of pages into a site whose every route is its semantic tree written as HTML and as Markdown; list a site's routes; read one page as an agent that only fetches would, without building the site.

Generated by `ops-gen` from the catalog; the effect is openas's.

| Operation | Effect | Parameters | Result | Cost | Undo | Cancel |
|---|---|---|---|---|---|---|
| `site.build` — Build the site: each page of pages/ a route with its index.html (the tree as HTML: readable with no script) and index.md (the tree as Markdown), the routes table, llms.txt and, given the site's address, sitemap.xml | reversible | `site`: path, `out`: path, `title`: string (optional), `languages`: string (optional), `url`: string (optional) | json | bounded | delete the directory written | no |
| `routes.list` — The routes a site's pages give: each its address, source, title, language and headings with their anchors | read | `site`: path, `languages`: string (optional) | json | instant | — | no |
| `page.read` — One route as it would be written, without building the site: its Markdown (what an agent that only fetches reads) or its HTML | read | `site`: path, `route`: string, `as`: string (optional), `languages`: string (optional) | json | bounded | — | no |
