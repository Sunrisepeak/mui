# nav operations

Build a navigation mesh from triangles, ask paths, rays and the nearest place on it, add walkers and send them, place obstacles and links, step the crowd, return to a frame, and ask what would be.

Generated by `omui-gen ops` from the catalog; the effect is openas's.

| Operation | Effect | Parameters | Result | Cost | Undo | Cancel |
|---|---|---|---|---|---|---|
| `nav.observe` — The frame, the state's hash, the mesh's tiles and polygons, how many walkers (by how they are going: idle, walking, arrived, unreachable, crossing a link, off the mesh), obstacles and links | read | — | json | instant | — | no |
| `nav.where` — Where a walker is (or every one): its place, velocity, how it is going, its target and the corners it steers for next | read | `walker`: integer (optional), `budget`: integer (optional) | json | instant | — | no |
| `nav.path` — The way between two places: its corners (those where a link begins marked), its length, whether it reaches the place asked or ends as near as it can, and how many polygons it crosses | read | `from`: json, `to`: json | json | instant | — | no |
| `nav.nearest` — The nearest place on the mesh to a place, within a reach | read | `at`: json, `reach`: json (optional) | json | instant | — | no |
| `nav.ray` — A straight walk along the mesh: whether it gets there, how far it goes and the wall's normal where it stops | read | `from`: json, `to`: json | json | instant | — | no |
| `nav.build` — The mesh built anew from triangles for one size of walker; the obstacles, links and walkers of the old one go | reversible | `points`: json, `corners`: json, `radius`: number (optional), `height`: number (optional), `climb`: number (optional), `slope`: number (optional) | json | bounded | nav.seek to the frame before it | no |
| `nav.add` — A walker of the crowd, at the nearest place on the mesh to `at` | reversible | `at`: json, `radius`: number (optional), `speed`: number (optional) | json | instant | nav.remove, or nav.seek to the frame before it | no |
| `nav.remove` — A walker taken out of the crowd | reversible | `walker`: integer | json | instant | nav.seek to the frame before it | no |
| `nav.target` — A walker sent to the nearest place on the mesh to `to`, its path planned whole now (or stopped, with no `to`) | reversible | `walker`: integer, `to`: json (optional) | json | instant | nav.seek to the frame before it | no |
| `nav.obstacle` — An obstacle placed (a cylinder or a box) or taken away (`remove`): the tiles under it are built again, and walkers whose way it crosses plan again | reversible | `shape`: string (optional), `at`: json (optional), `radius`: number (optional), `height`: number (optional), `half`: json (optional), `remove`: integer (optional) | json | bounded | nav.obstacle with `remove`, or nav.seek to the frame before it | no |
| `nav.link` — Two places joined that a walker could not walk between (a jump, a ladder), or a link taken away (`remove`): the tile where it starts is built again | reversible | `from`: json (optional), `to`: json (optional), `radius`: number (optional), `both_ways`: boolean (optional), `remove`: integer (optional) | json | bounded | nav.link with `remove`, or nav.seek to the frame before it | no |
| `nav.step` — Steps the crowd: every walker steered along its corridor, kept apart, moved on the mesh, carried across a link | reversible | `steps`: integer (optional) | json | bounded | nav.seek to the frame it began at | no |
| `nav.seek` — Returns to a frame within the history kept, bit for bit (a checkpoint and the inputs since, given again); what is stepped from there is a new branch | reversible | `frame`: integer | json | bounded | none within the world: what came after the frame is another branch's | no |
| `nav.branch` — What would be: the world some steps ahead, a walker sent somewhere first if one is given, observed as nav.observe does; the world itself untouched | read | `steps`: integer (optional), `walker`: integer (optional), `to`: json (optional) | json | bounded | — | no |

## Tasks to begin with

Each step is a request as it is sent; `describe` gives the same to an agent.

**find-the-way** — Read the mesh, then the way between two places and how far a straight walk gets

```json
{"op":"nav.observe"}
{"op":"nav.path","from":[-5,0,-5],"to":[5,0,-5]}
{"op":"nav.ray","from":[-5,0,-5],"to":[5,0,-5]}
```

**send-a-walker** — Add a walker, send it, step the crowd and read where it got to

```json
{"op":"nav.add","at":[-5,0,-6]}
{"op":"nav.target","walker":1,"to":[5,0,-5]}
{"op":"nav.step","steps":300}
{"op":"nav.where","walker":1}
```

**block-and-see** — Ask what an obstacle would do before placing it: a branch ahead, then the obstacle and the path again

```json
{"op":"nav.branch","steps":60}
{"op":"nav.obstacle","shape":"cylinder","at":[0,0,11.5],"radius":1.2,"height":2}
{"op":"nav.path","from":[-5,0,-5],"to":[5,0,-5]}
```
