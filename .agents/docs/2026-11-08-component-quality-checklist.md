# 组件质感细节清单（B4–B6）

2026-11-08。[官网重构与 Mui 方案](2026-11-08-site-redesign-mui-design.md) §3.4 要求的逐组件细节清单。每条对应 §3.1–§3.3 的一项规范，落在**框架**（主题令牌、默认动效规则、组件本身），不落在官网。状态：✓ 已完成，◐ 已在 `refined` 中（待批准后成为默认），○ 待做。

## 0. 做法

- 新的取值先进 `refined` 叠加层（`default.theme.omui.toml` 的 `[theme.refined]`），框架默认和所有钉住值不动；对照图（`site/tests/quality_lab_test.cpp`，scratch `quality-lab/controls.png`：每个控件静止、悬停、按下、键盘焦点四态，左四列默认、右四列 refined；第一版见 [media/2026-11-08-quality/controls.png](media/2026-11-08-quality/controls.png)）交维护者批准。
- 批准后在**一个检查点**里把 `refined` 的取值并入 `light`／`dark`，删除这个叠加层，同时更新钉住值。
- 组件不写死质感数值：圆角平滑由框架统一套到组件自己画的形状上（`DisplayList::smooth_corners`）；深度来自阴影令牌（`parts::depth`：`<令牌>`、`<令牌>:hovered`、`<令牌>:pressed`）；阴影可以带投射物的颜色（`tint`）。
