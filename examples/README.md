# examples

Small, real tools; each shows one thing the framework does, and each has headless tests with pinned pixels. Example 11 grew into the [Markdown wall](../showcase/markdown-wall).

| Example | What it is | What it shows |
|---|---|---|
| [01-hello-im](01-hello-im) | Hello, immediate mode | The whole application in one function |
| [02-hello-ts](02-hello-ts) | Text statistics in TypeScript | The player, scripts |
| [03-counter](03-counter) | A tally counter | Five ways to write it, one semantic tree |
| [04-rating](04-rating) | A rated reading list | An application's own component, contract to every language |
| [05-contrast](05-contrast) | A WCAG contrast checker | An application's own native module |
| [06-theming](06-theming) | A theme preview in Lua | Themes, density, motion, an application's own theme |
| [07-headless-and-agent](07-headless-and-agent) | A notes application | Headless tests, agent scripts, effects stopped until answered |
| [08-markdown-viewer](08-markdown-viewer) | A Markdown viewer | A live table of contents, document links, reload on save |
| [09-markdown-stream](09-markdown-stream) | Markdown as it streams in | Incremental parsing, new words fading in |
| [10-canvas-basics](10-canvas-basics) | Where a folder's space went | The infinite canvas, a treemap |
| [12-notes](12-notes) | Markdown notes | TypeScript, Lua, a view document and C++ in one application |
