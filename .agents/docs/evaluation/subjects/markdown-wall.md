# Subject: markdown-wall — the document wall

**What:** `showcase/markdown-wall`: a folder's Markdown documents as windows on an infinite canvas — tiers of detail by zoom, live windows, declarative behaviours, streaming, search, minimap, groups; 1000 windows within budget. Read its README, dev-story.md, the canvas-markdown design document, components/canvas and components/markdown, src/, tests/, tests/bench canvas results.

**Top 3:** Figma / FigJam · tldraw · Obsidian Canvas. **Reference:** Miro, Heptabase.

**Dimensions:**
- `usefulness` — would someone open their notes in it daily: open, read, search, arrange, link, save.
- `canvas_ux` — pan, zoom, select, drag, snap, groups, minimap, named views; versus the top 3.
- `semantic_zoom` — readability at every tier: overview, summary, reading.
- `window_design` — chrome, titles, paths, elevation, selection and focus states.
- `markdown_rendering` — typography, headings, code, tables, lists, links, CJK.
- `layout_arrangement` — the wall's arrangement, grouping, use of space.
- `performance` — 1000 and 100k windows, sharpen times, allocation; measured.
- `persistence_navigation` — saved arrangement and camera, links between documents, back/forward.
- `framework_showcase` — tiers, live windows, behaviours, streaming shown naturally.
- `code_tests_docs` — code, tests, README, dev story, signature shot.
