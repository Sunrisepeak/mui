# showcase

Flagship works: each is a real tool, shows a feature of the framework, and has a signature shot that replays exactly under the headless host (D-63).

| Work | What it is | What it shows |
|---|---|---|
| [fighting](fighting) | 格斗游戏, the fighting game: gongfu's match, played from the keyboard or by an agent, with a training mode | Deterministic rollback simulation on the runtime's clock; the game as a semantic node an agent plays; boxes and the frame meter |
| [markdown-wall](markdown-wall) | A wall of a folder's documents on an infinite canvas | Tiers of detail, live windows, declarative behaviours, streaming; 1000 windows within budget |
| [style-gallery](style-gallery) | A settings panel and dashboard in five style packs | Slang effects, cross-fades, the same semantic tree in every style |
| [widget-breakout](widget-breakout) | 《组件打砖块》, a breakout whose bricks are real components (S4; levels 1–5 so far) | Each level's play is one of openmui's abilities; deterministic, rewindable, an agent's test bed |
