# inspector operations

Read, edit, step and replay the Inspector's cellular material field.

Generated by `omui-gen ops` from the catalog; the effect is openas's.

| Operation | Effect | Parameters | Result | Cost | Undo | Cancel |
|---|---|---|---|---|---|---|
| `cellular.describe` — Discover the integer rule project format, budgets and editing SOP. | read | — | json | instant | — | no |
| `cellular.snapshot` — Read revision, simulation tick, replay frame, brushes and current state hash. | read | — | json | instant | — | no |
| `cellular.project` — Export the current state as a reloadable cellular project; history is not serialized. | read | — | json | bounded | — | no |
| `cellular.config` — Read editable rules, palette, brushes, rate and boundary. | read | — | json | instant | — | no |
| `cellular.inspect` — Read all channels of one cell at x/y. | read | `x`: integer, `y`: integer | json | instant | — | no |
| `cellular.load` — Validate and load a project atomically; starts a new replay history. | reversible | `project`: json, `revision`: integer (optional) | json | bounded | ui.undo restores the field before it | no |
| `cellular.configure` — Validate an edited rule/palette configuration over the current field. | reversible | `config`: json, `revision`: integer (optional) | json | bounded | ui.undo restores the configuration before it | no |
| `cellular.paint` — Paint an integer-radius brush at x/y; records an input without advancing simulation time. | reversible | `x`: integer, `y`: integer, `radius`: integer, `brush`: string, `revision`: integer (optional) | json | instant | ui.undo restores the cells before it | no |
| `cellular.advance` — Advance 1..120 fixed simulation steps; retained history can be sought. | reversible | `count`: integer, `revision`: integer (optional) | json | bounded | cellular.seek to the frame cellular.snapshot read before | no |
| `cellular.seek` — Restore a retained replay frame exactly, including paint inputs. | reversible | `frame`: integer, `revision`: integer (optional) | json | bounded | cellular.seek to the frame before | no |
| `cellular.reset` — Restore this project's initial state; starts a new replay history. | reversible | `revision`: integer (optional) | json | instant | ui.undo restores the field before it | no |
| `cellular.play` — Start or stop live playback; continuation rechecks the initiating Agent authority. | reversible | `enabled`: bool, `revision`: integer (optional) | json | instant | cellular.play with the other enabled | no |
