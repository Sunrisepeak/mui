# particles operations

Read a cloud of particles in flight — where each is, what it is made of, how hot — and what struck the world, find those near a place, emit more, step it, return to a frame, and ask what would be.

Generated by `omui-gen ops` from the catalog; the effect is openas's.

| Operation | Effect | Parameters | Result | Cost | Undo | Cancel |
|---|---|---|---|---|---|---|
| `particles.observe` — The frame, the cloud's fingerprint, how many are in flight (by material), what struck the world in the last step (fastest first) and how many things matter's laws did | read | `budget`: integer (optional) | json | instant | — | no |
| `particles.list` — Particles in the order emitted: id, material, place, velocity, age, life left and temperature in kelvin | read | `first`: integer (optional), `most`: integer (optional) | json | bounded | — | no |
| `particles.near` — The particles within a distance of a place, the nearest first, as particles.list gives them | read | `at`: json, `radius`: number (optional), `most`: integer (optional) | json | bounded | — | no |
| `particles.emit` — Particles of a material emitted on the next step: at a place, at a speed — `count` of them, their speeds spread by up to `spread` m/s each way, the same spread every run | reversible | `at`: json, `velocity`: json (optional), `material`: string, `kelvin`: number (optional), `life`: number (optional), `size`: number (optional), `count`: integer (optional), `spread`: number (optional) | json | instant | particles.seek to the frame before it took effect | no |
| `particles.step` — Steps the cloud: flight, the world's surfaces met, one tick of matter's laws | reversible | `steps`: integer (optional) | json | bounded | particles.seek to the frame it began at | no |
| `particles.seek` — Returns to a frame within the history kept, bit for bit (a copy of the cloud and the emissions since, played again); what is stepped from there is a new branch | reversible | `frame`: integer | json | bounded | none within the cloud: what came after the frame is another branch's | no |
| `particles.branch` — What would be: the cloud some steps ahead, particles emitted first if `at` and `material` are given (as particles.emit takes them), observed as particles.observe does; the cloud itself untouched | read | `steps`: integer (optional), `at`: json (optional), `velocity`: json (optional), `material`: string (optional), `kelvin`: number (optional), `life`: number (optional), `size`: number (optional), `count`: integer (optional), `spread`: number (optional) | json | bounded | — | no |

## Tasks to begin with

Each step is a request as it is sent; `describe` gives the same to an agent.

**see-what-is-in-flight** — Read the cloud, then the first particles and those near the middle

```json
{"op":"particles.observe"}
{"op":"particles.list","first":0,"most":16}
{"op":"particles.near","at":[0,0,0],"radius":1}
```

**throw-sparks** — Emit hot iron sparks, step a second, and read what struck the world and how hot they are now

```json
{"op":"particles.emit","at":[0,1,0],"velocity":[0,3,0],"material":"iron","kelvin":1500,"count":20,"spread":1}
{"op":"particles.step","steps":60}
{"op":"particles.observe"}
{"op":"particles.list","most":4}
```

**ask-before-emitting** — See what an emission would do a second ahead, the cloud itself untouched

```json
{"op":"particles.branch","steps":60,"at":[0,1,0],"velocity":[0,3,0],"material":"iron","kelvin":1500,"count":20,"spread":1}
{"op":"particles.observe"}
```
