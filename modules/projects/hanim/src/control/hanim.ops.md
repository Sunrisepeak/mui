# hanim operations

Prepare, play, inspect and steer animations on a host's one Engine.

Generated by `omui-gen ops` from the catalog; the effect is openas's.

| Operation | Effect | Parameters | Result | Cost | Undo | Cancel |
|---|---|---|---|---|---|---|
| `animation.prepare` — Prepare an immutable animation plan | read | `program`: program | plan | bounded | — | no |
| `animation.play` — Start an authored or prepared animation | reversible | `program`: program | playback | bounded | animation.cancel with restore puts its objects back | no |
| `animation.list` — List owned playback identities and transport state | read | — | json | instant | — | no |
| `animation.inspect` — Read one playback's transport state | read | `playback`: playback | json | instant | — | no |
| `animation.plan` — Read its immutable plan and channels | read | `playback`: playback | plan | instant | — | no |
| `animation.seek` — Sample absolute seconds | reversible | `playback`: playback, `position`: seconds | — | frame | seek back to the position animation.inspect read | no |
| `animation.seek-progress` — Sample normalized progress | reversible | `playback`: playback, `progress`: number | — | frame | seek back to the progress animation.inspect read | no |
| `animation.pause` — Pause transport | reversible | `playback`: playback | — | instant | animation.resume | no |
| `animation.resume` — Resume transport | reversible | `playback`: playback | — | instant | animation.pause | no |
| `animation.reverse` — Reverse transport direction | reversible | `playback`: playback | — | instant | animation.reverse again | no |
| `animation.rate` — Set a nonzero signed rate | reversible | `playback`: playback, `rate`: number | — | instant | animation.rate with the rate animation.inspect read | no |
| `animation.cancel` — Cancel a playback; optionally restore its initial pose | irreversible | `playback`: playback, `restore`: bool (optional) | — | instant | none: a cancelled playback stays cancelled (play its program again) | no |
| `animation.release` — Release a playback and invalidate its handle | irreversible | `playback`: playback | — | instant | none: the handle is gone (play its program again for a new one) | no |
