# terminal operations

Read an application's picture in a terminal: its cells as text, their colours and style, and what drew one.

Generated by `ops-gen` from the catalog; the effect is openas's.

| Operation | Effect | Parameters | Result | Cost | Undo | Cancel |
|---|---|---|---|---|---|---|
| `terminal.frame` — The frame as the terminal shows it: its size in cells, the grid in the interface's pixels, its text a row a line; with `cells`, each cell's grapheme, colours (#rrggbb), style and the node that drew it | read | `cells`: bool (optional) | json | instant | — | no |
| `terminal.at` — What drew a cell: its grapheme, colours and style, and the node that drew it last — its id and path in the interface — with the point in the interface's pixels a pointer there would hit | read | `at`: json | json | instant | — | no |

## Tasks to begin with

Each step is a request as it is sent; `describe` gives the same to an agent.

**read-the-screen** — Read what the terminal shows, a row a line

```json
{"op":"terminal.frame"}
```

**ask-what-drew-a-cell** — Go from a cell back to the node that drew it

```json
{"op":"terminal.at","at":[2,1]}
```
