# openmui.native.fuzzy

[openmui.fuzzy](../../modules/fuzzy) for scripts: the official native module that every host registers (the player, the Python extension). Its contract, [`native/fuzzy.native.omui.toml`](native/fuzzy.native.omui.toml), is all that is written about the interface. The partition `src/generated/fuzzy_native.cppm` and the stubs in `stubs/` are generated by `omui-gen native`, and tools/gen's test keeps them current.

```ts
import { fuzzy } from "openmui:native/fuzzy";
const best = await fuzzy.rank(query, files, 20);   // Match[]: index, text, score, positions, segments
```

```python
from openmui.native import fuzzy
best = fuzzy.rank(query, files, 20)
```

```lua
local best = omui.native.fuzzy.rank(query, files, 20)
```

The three are one result: the conformance scenario `spec/conformance/S/finder.scenario.omui.json` calls it from each language, from a handler as a person types and from its steps, and requires the same trace (M3 acceptance ⑥).
