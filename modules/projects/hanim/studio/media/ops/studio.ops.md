# studio operations

Check, sample, point into, vary and render hanim animation documents (<name>.animation.omui.json) headless.

Generated by `omui-gen ops` from the catalog; the effect is openas's.

| Operation | Effect | Parameters | Result | Cost | Undo | Cancel |
|---|---|---|---|---|---|---|
| `document.check` — The document's plan (duration, tracks, segments, markers, stage size) and the operations it took, or every problem at its JSON pointer (syntax at line and column) | read | `file`: path | json | bounded | — | no |
| `document.sample` — Every object at given moments: drawn or not, position, scale, rotation, fill, group opacity and the bounds it covers | read | `file`: path, `at`: json | json | bounded | — | no |
| `document.at` — What governs a moment someone points at: the steps that run then (of one object, if given), innermost first — each one's JSON pointer, start, end, how far through it is, the objects it moves and its own JSON: what to change to change what is seen | read | `file`: path, `at`: number, `object`: string (optional) | json | bounded | — | no |
| `document.vary` — Alternatives a person picks from by looking: one value (at a JSON pointer) set several ways, every variant drawn at the same moments, a row each under the document as written — a sheet, each variant's document, and a report with each one's duration, frame hashes or problems | reversible | `file`: path, `set`: string, `value`: json, `out`: path, `frames`: integer (optional), `at`: json (optional) | json | heavy | delete the written files | no |
| `document.render` — The stage drawn at evenly spaced or given moments: PNG frames (and SVG), a strip of them, an optional animated WebP and a report with each frame's pixel hash and objects | reversible | `file`: path, `out`: path, `frames`: integer (optional), `at`: json (optional), `webp`: integer (optional), `svg`: bool (optional) | json | heavy | delete the written files | no |
