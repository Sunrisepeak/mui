# rigid3 operations

Read a 3D rigid world's bodies, joints, characters and what touched what, cast a ray or a shape into it, push a body, drive a joint's motor, walk and jump a character, step it, return to a frame, and ask what would be.

Generated by `omui-gen ops` from the catalog; the effect is openas's.

| Operation | Effect | Parameters | Result | Cost | Undo | Cancel |
|---|---|---|---|---|---|---|
| `rigid3.observe` — The frame, the state's hash, how many bodies (and how many awake), joints and characters, and what began and ended touching in the last step (a sensor's overlaps marked `sensor`) | read | `budget`: integer (optional) | json | instant | — | no |
| `rigid3.bodies` — Each body's id, kind, place, turn, velocity and whether it is awake, in the order made | read | — | json | bounded | — | no |
| `rigid3.ray` — The first body a segment meets: which, how far along, where and the surface's normal there | read | `from`: json, `to`: json | json | instant | — | no |
| `rigid3.cast` — The first body a shape swept along a segment meets: which, how far along, where and the surface's normal there | read | `shape`: string (optional), `radius`: number (optional), `half`: json (optional), `half_height`: number (optional), `from`: json, `to`: json | json | instant | — | no |
| `rigid3.joints` — Each joint's id, form, bodies (0: the world), value (a hinge's angle, a slider's place, a distance joint's length) and motor, in the order made | read | — | json | bounded | — | no |
| `rigid3.drive` — A hinge's or a slider's motor, from the next step: off, toward a speed, or toward an angle or a place | reversible | `joint`: integer, `mode`: string (optional), `target`: number (optional) | json | instant | rigid3.seek to the frame before it took effect | no |
| `rigid3.move` — A character's walk, from the next step until told otherwise: up steps and the slopes it can climb, stuck to the floor going down | reversible | `character`: integer, `velocity`: json | json | instant | rigid3.seek to the frame before it took effect | no |
| `rigid3.jump` — A character's jump on the next step, when it stands on the ground (the answer says whether it does now) | reversible | `character`: integer, `speed`: number (optional) | json | instant | rigid3.seek to the frame before it took effect | no |
| `rigid3.where` — Where a character is (or every one): its feet, its velocity and walk, and what it stands on | read | `character`: integer (optional) | json | instant | — | no |
| `rigid3.ground` — What each character stood on after the last step, in the order of their ids: on the ground, on steep ground, not supported or in the air, and which body | read | — | json | bounded | — | no |
| `rigid3.push` — An impulse on a body, given on the next step: through its centre of mass, or at a point in the world | reversible | `body`: integer, `impulse`: json, `at`: json (optional) | json | instant | rigid3.seek to the frame before it took effect | no |
| `rigid3.step` — Steps the world | reversible | `steps`: integer (optional) | json | bounded | rigid3.seek to the frame it began at | no |
| `rigid3.seek` — Returns to a frame within the history kept, bit for bit (a checkpoint and the pushes since, played again); what is stepped from there is a new branch | reversible | `frame`: integer | json | bounded | none within the world: what came after the frame is another branch's | no |
| `rigid3.branch` — What would be: the world some steps ahead, a body pushed first if one is given, observed as rigid3.observe does; the world itself untouched | read | `steps`: integer (optional), `body`: integer (optional), `impulse`: json (optional) | json | bounded | — | no |

## Tasks to begin with

Each step is a request as it is sent; `describe` gives the same to an agent.

**see-what-is-there** — Read the bodies, then what lies straight down from above

```json
{"op":"rigid3.observe"}
{"op":"rigid3.bodies"}
{"op":"rigid3.ray","from":[0,20,0],"to":[0,-20,0]}
```

**push-and-watch** — Push a body, step the world, and read what it struck

```json
{"op":"rigid3.push","body":1,"impulse":[0,400,0]}
{"op":"rigid3.step","steps":30}
{"op":"rigid3.observe"}
```

**walk-a-character** — Walk a character, step, and read where it stands

```json
{"op":"rigid3.where"}
{"op":"rigid3.move","character":1,"velocity":[2,0,0]}
{"op":"rigid3.step","steps":60}
{"op":"rigid3.ground"}
```

**turn-a-motor** — Read the joints, drive a hinge's motor, step, and read its angle

```json
{"op":"rigid3.joints"}
{"op":"rigid3.drive","joint":1,"mode":"velocity","target":2}
{"op":"rigid3.step","steps":60}
{"op":"rigid3.joints"}
```

**ask-before-pushing** — See what a push would do some steps ahead, the world itself untouched

```json
{"op":"rigid3.branch","steps":30,"body":1,"impulse":[0,400,0]}
{"op":"rigid3.observe"}
```
