# omui 文档

给用它做东西的人：应用开发者、游戏开发者、让 Agent 干活的人。引擎内部怎么设计不在这里（见[设计文档](../../.agents/docs/README.md)）。

每项能力在哪个平台上跑过（实机、软件，还是尚未验证）见[平台](platforms.md)。每个包的成熟度（稳定、预览或实验，以及每种标注承诺什么）见[成熟度](maturity.md)；标为实验、随发布提供的部分及其目标与差距见[实验](experimental.md)。指南里的代码都节选自 CI 构建并运行的文件（lint `docs-code`）。每个操作目录与组件契约见 [API 参考](reference.md)，由声明生成。发布前每个项目的收口清单走到哪一步见[收口清单](closure.md)。

## 今天能用它做什么

| 你想做 | 用什么 | 成熟度 | 从这里开始 |
|---|---|---|---|
| 桌面与 Web 的界面、工具 | omui | 稳定 | [上手](guide/start.md) → [写界面](guide/ui.md) |
| 让 Agent 读懂并操作你的应用 | omui 的 Agent 面、`omui agent`、MCP | 稳定 | [Agent](guide/agent.md) |
| 界面动效、代码生成的动画与视频 | hanim | 稳定（studio：预览） | [动效](guide/motion.md) |
| 会燃烧、流动、凝固的 2D 物质世界 | meng 的物质与格点 | 预览 | [物质世界](guide/world.md) |
| 不开窗口也能跑、Agent 能玩的 2D 游戏 | meng 的游戏运行时 | 预览 | [游戏](guide/game.md) |
| 三维世界：刚体、人群、穿墙的声音；场景、网格、阴影、glTF | meng 的内核、xrender 的 scene 与 mesh | 预览 | [三维世界](guide/world3d.md) → [Quay](../../showcase/quay) |

**稳定**：过全部质量门，0.1.x 内源码兼容。**预览**：在声明的范围内过全部质量门，接口会变。**实验**：能构建、原理成立，离自己的目标还有差距。每个包的标注见[成熟度](maturity.md)。整个项目仍在开发阶段，尚未发布版本（2026-11-17）。

## 三个要先知道的想法

1. **界面是一棵语义树。** 屏幕上的像素、读屏软件念的内容、Agent 读到并操作的东西、测试断言的对象，都来自同一棵树。所以你写一次，四样都有。
2. **人和 Agent 是同等的使用者。** 人能点的，Agent 都能做；Agent 能做什么由你和用户决定，不可撤销的操作要人确认。
3. **同样的输入，同样的结果。** 动画是时间的函数，模拟按固定步长走，所以任何一帧都能重现、回放、分叉出去试。
