# video operations

Films on exact frame and sample counts: render a description to WebM, Y4M, PNG or WAV, take a still, check a description, probe a file, show the timing. A view's frames are omui's, through a composition that adds them.

Generated by `ops-gen` from the catalog; the effect is openas's.

| Operation | Effect | Parameters | Result | Cost | Undo | Cancel |
|---|---|---|---|---|---|---|
| `video.render` — A video rendered to files on exact frame and sample counts: WebM (VP9 and Opus), Y4M (and a WAV beside it), a PNG sequence, or a WAV | reversible | `file`: path, `out`: path, `size`: string (optional), `fps`: string (optional), `seconds`: number (optional), `frames`: integer (optional), `format`: string (optional), `quality`: integer (optional), `bitrate`: integer (optional), `speed`: integer (optional), `realtime`: bool (optional), `lossless`: bool (optional), `threads`: integer (optional), `audio-bitrate`: integer (optional) | json | heavy | delete the files written | no |
| `video.still` — One frame of a video as a PNG | reversible | `file`: path, `out`: path, `frame`: integer (optional), `at`: number (optional), `size`: string (optional), `fps`: string (optional), `seconds`: number (optional), `frames`: integer (optional) | json | bounded | delete the PNG | no |
| `video.check` — Whether a video description reads: its problems, or its size, rate, frames and samples | read | `file`: path, `size`: string (optional), `fps`: string (optional), `seconds`: number (optional), `frames`: integer (optional) | json | bounded | — | no |
| `video.probe` — What a WebM, Y4M or WAV file holds (a WebM decoded: its frames and samples counted) | read | `file`: path | json | bounded | — | no |
| `video.timing` — Each frame's first sample and length, and its start in nanoseconds | read | `fps`: string (optional), `rate`: integer (optional), `frames`: integer (optional) | json | instant | — | no |
