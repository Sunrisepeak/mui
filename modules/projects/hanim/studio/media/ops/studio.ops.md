# studio operations

Check, sample and render hanim animation documents (<name>.animation.omui.json) headless.

Generated by `omui-gen ops` from the catalog; the effect is openas's.

| Operation | Effect | Parameters | Result | Cost | Undo | Cancel |
|---|---|---|---|---|---|---|
| `document.check` — The document's plan (duration, tracks, segments, markers, stage size) and the operations it took, or every problem at its JSON pointer (syntax at line and column) | read | `file`: path | json | bounded | — | no |
| `document.sample` — Every object at given moments: drawn or not, position, scale, rotation, fill, group opacity and the bounds it covers | read | `file`: path, `at`: json | json | bounded | — | no |
| `document.render` — The stage drawn at evenly spaced or given moments: PNG frames (and SVG), a strip of them, an optional animated WebP and a report with each frame's pixel hash and objects | reversible | `file`: path, `out`: path, `frames`: integer (optional), `at`: json (optional), `webp`: integer (optional), `svg`: bool (optional) | json | heavy | delete the written files | no |
