# 一棵树，多种呈现

openmui 是一个 UI 框架，也是一份开放的规范，建立在一个想法上：**界面是一棵语义树**，其他一切都是它的呈现。

- 你看到的**像素**是一种呈现，每个平台上逐位相同。
- **辅助技术**读的是另一种：树上的角色、名字和状态。
- **agent** 把这棵树当数据读，用和人的输入同一组动作操作它，经过同样的检查，可以同样地撤销。
- **测试**对这棵树断言，并固定像素。

这个网站本身用 openmui 做成。切换上方的**镜头**，可以看到你正在读的这一页的每一种呈现：像素、语义树的线框、agent 收到的 JSON、测试会写下的断言。

## 这里有什么

- **特性**和**实践**：框架的文档，中英两种语言。
- **时间线**：一个真正可用的时间线编辑器。拖动片段、拖边修剪、按 S 在播放头处切开，再按 Ctrl+Z。每次编辑都是一个精确的修改，带着它精确的反向。

页脚显示你的浏览器算出的语义树哈希。确定性是设计的一部分：每台机器上都是同一棵树。
