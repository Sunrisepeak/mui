# skeleton operations

Play skeletal characters: read the rig and each character's state, send one to a state or set its parameters, layer a clip on part of it, ask where a joint is, sample any clip at any time, step, return to a frame, and ask what would be.

Generated by `omui-gen ops` from the catalog; the effect is openas's.

| Operation | Effect | Parameters | Result | Cost | Undo | Cancel |
|---|---|---|---|---|---|---|
| `skeleton.observe` — The frame, the state's hash, the rig (joints; clips with their length, raw and compressed bytes and compression error; the machine's states and parameters) and each character: its state, how far its fade is, the last transition and why, its parameters, layers and where it stands | read | `budget`: integer (optional) | json | instant | — | no |
| `skeleton.play` — Sends a character to a state of its machine now, fading over some seconds (no condition asked) | reversible | `character`: integer, `state`: string, `fade`: number (optional) | json | bounded | skeleton.seek to the frame it was given at | no |
| `skeleton.set` — Sets a parameter of a character's machine (a trigger: 1); its transitions read it from the next step | reversible | `character`: integer, `parameter`: string, `value`: number | json | bounded | skeleton.seek to the frame it was given at | no |
| `skeleton.blend` — Layers a clip over what the machine plays: mixed in by a weight (on a joint's subtree when a mask is given) or added (its difference from its own start); a weight of 0 takes the layer away | reversible | `character`: integer, `layer`: integer (optional), `clip`: string (optional), `weight`: number, `mask`: string (optional), `additive`: boolean (optional), `speed`: number (optional) | json | bounded | skeleton.blend with weight 0, or skeleton.seek | no |
| `skeleton.joint` — Where a joint is: in the world (the character's place, then the joint in the model's space), its turn and its place relative to the model | read | `character`: integer, `joint`: string | json | instant | — | no |
| `skeleton.sample` — Any clip at any time, as a pure function of it: a joint's place in the model (or every joint's, within a budget), the root motion from the clip's start, and the error compression left there | read | `clip`: string, `time`: number, `joint`: string (optional), `budget`: integer (optional) | json | instant | — | no |
| `skeleton.step` — Steps every character (1/60 s a step): machines choose, clips play, root motion carries them | reversible | `steps`: integer (optional) | json | bounded | skeleton.seek to the frame it began at | no |
| `skeleton.seek` — Returns to a frame within the history kept, bit for bit (a checkpoint and the inputs since, given again); what is stepped from there is a new branch | reversible | `frame`: integer | json | bounded | none within the world: what came after the frame is another branch's | no |
| `skeleton.branch` — What would be: the characters some steps ahead, one sent to a state first if one is given, observed as skeleton.observe does; the characters themselves untouched | read | `steps`: integer (optional), `character`: integer (optional), `state`: string (optional) | json | bounded | — | no |

## Tasks to begin with

Each step is a request as it is sent; `describe` gives the same to an agent.

**read-the-rig** — Read the rig and the characters, then sample a clip where a foot lands

```json
{"op":"skeleton.observe"}
{"op":"skeleton.sample","clip":"walk","time":0.5,"joint":"foot_r"}
```

**make-one-run** — Set a character's speed, step through the fade, and check where its hand is and that it moved forward

```json
{"op":"skeleton.set","character":0,"parameter":"speed","value":3}
{"op":"skeleton.step","steps":60}
{"op":"skeleton.observe"}
{"op":"skeleton.joint","character":0,"joint":"hand_r"}
```

**wave-while-walking** — Ask what a wave on the upper body would look like before giving it: a branch ahead, then the layer and a step

```json
{"op":"skeleton.branch","steps":30}
{"op":"skeleton.blend","character":1,"layer":0,"clip":"wave","weight":1,"mask":"upper_chest"}
{"op":"skeleton.step","steps":30}
{"op":"skeleton.joint","character":1,"joint":"hand_r"}
```
