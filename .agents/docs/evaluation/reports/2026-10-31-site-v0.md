**Top 7 fixes — concrete redesign**

1. **Rebuild the first viewport around “One interface. Every perspective.”** At 1440px, use a 72px header, 80px outer gutters and a 1200–1280px content width. Put a 64–72px headline and two short supporting lines in a 440px left column; place a 720×460px live workspace on the right. Primary action: **Build with openmui**. Secondary: **Explore this interface**.

2. **Create an identity called into being by the product.** Use a branching mark whose four terminals resolve into a pixel corner, focus outline, action cursor and assertion tick. Palette: ink `#10131A`, warm white `#F4F2EC`, violet `#8578FF`; reserve amber for actions requiring attention and mint for verified results. Use a restrained 8px spacing system, Inter for reading and JetBrains Mono for data. Give expressive display lettering to the hero, without spreading novelty through documents.

3. **Signature interaction 1: “Follow one action.”** Use a real, reusable release checklist. Selecting “Ship v0.1” highlights the same stable node in four adjacent views: rendered control, accessible role/name/state, agent request, passing assertion. Animate correspondence over 180–240ms. Let a person or the scripted agent perform the task; show permission handling only when an actual external action requires it.

4. **Signature interaction 2: “Hold this moment.”** After a language or style change, offer a visible 12-second replay strip with three event thumbnails. Scrubbing freezes glyphs, camera and shader parameters at an exact timestamp. Show historical drawing and current semantics with explicit labels. A **Verify this frame** action compares the CPU reference with CI; GPU comparison uses its stated tolerance.

5. **Signature interaction 3: “Same meaning, different matter.”** Apply glass, ink and high-contrast treatments to that same useful workspace. A draggable divider reveals the material change while stable node IDs remain connected. Provide editable GPU effect parameters, measured rendering cost and an unchanged semantic fingerprint. Export the chosen theme through a browser download.

6. **Recompose Explore and the embedded works.** Use a two-column atlas of six curated, recognisable scenes, each with a 24px title, purpose and explicit entry control. Open the wall on a readable document cluster; give the timeline a preview and editable project; enlarge the move inspector and simplify its HUD. Put source behind an optional, syntax-highlighted panel.

7. **Remove competing first-visit machinery.** Remove the permanent left sidebar and hash-heavy footer from the landing page, benchmark filler from the default wall, S1/S2 labels, raw JSON as the default inspection experience, and the click counter as a flagship destination. Retain these in developer inspection. Add the missing development story and enforce visual, accessibility, motion and browser-performance acceptance checks.
