# mlibs.names

The nearest name for a typo: `nearest(name, options)` gives "did you mean `x`?" within a third of the name, never for a whole one-letter name; otherwise it lists the options. `distance` counts edits, a swap of two neighbours as one.

The one implementation: the readers of data files (with `mlibs.json`), the laws of `xengine.matter`, anything that resolves a name a person or an agent wrote. It was `mlibs.json`'s until a reader that takes no JSON needed it (2026-11-13).
