# oweb operations

A site states its title, address, languages, routes and budget in its oweb.config.ts; every operation reads it and a request's options stand over it. Build a directory of pages into a site whose every route is its semantic tree written as HTML and as Markdown. Ask a site what it is, list its routes, read one page as an agent that only fetches would, and search every page's sections — of its source, without building it, or of the site as built: the directory a build wrote, read as it was published.

Generated by `ops-gen` from the catalog; the effect is openas's.

| Operation | Effect | Parameters | Result | Cost | Undo | Cancel |
|---|---|---|---|---|---|---|
| `site.build` — Build the site: each page of pages/ a route with its index.html (the tree as HTML: readable with no script) and index.md (the tree as Markdown), the routes table, llms.txt, the search index, 404.html for a lost address, given the site's address sitemap.xml, and the delivery manifest — every file as stored and as a static host sends it, each route's bytes before it reads held to a budget (over it: written, and failed with where). A link inside the site that leads nowhere fails the build with each one said, and nothing is written | reversible | `site`: path, `config`: path (optional), `out`: path, `title`: string (optional), `languages`: string (optional), `url`: string (optional), `readable`: string (optional), `engine`: path (optional), `load`: string (optional) | json | bounded | delete the directory written | no |
| `site.describe` — What a site is, as it says it at each of its doors: its title, address and languages, each route with its title and its Markdown's address, the requests to go on with — and the text a build writes as llms.txt, the same words an agent that only fetches is given | read | `site`: path, `config`: path (optional), `languages`: string (optional), `url`: string (optional) | json | instant | — | no |
| `routes.list` — The routes a site's pages give: each its address, source, title, language and headings with their anchors | read | `site`: path, `config`: path (optional), `languages`: string (optional) | json | instant | — | no |
| `page.read` — One route as it is written — evaluated now from a site's source, or read from a site as built: its Markdown (what an agent that only fetches reads) or its HTML | read | `site`: path, `config`: path (optional), `route`: string, `as`: string (optional), `languages`: string (optional) | json | bounded | — | no |
| `docs.search` — The sections of a site's pages that hold every word asked for, best first: each its route, its anchor, the headings it is under and the line that says so — the same index a built site serves as site.search.xdef.json | read | `site`: path, `config`: path (optional), `query`: string, `limit`: string (optional), `languages`: string (optional) | json | bounded | — | no |
