# matter operations

Read a field of matter by material and in units, place a material, apply a quantity, ask why a cell is what it is, what happened, and what would.

Generated by `omui-gen ops` from the catalog; the effect is openas's.

| Operation | Effect | Parameters | Result | Cost | Undo | Cancel |
|---|---|---|---|---|---|---|
| `matter.describe` — What the world is made of: its materials, its channels with their units, its laws by name, kind and place in the definition; one material's properties or one law in full when named | read | `material`: string (optional), `law`: string (optional) | json | bounded | — | no |
| `matter.observe` — A region as matter: how many cells of each material, each channel in its unit (least, most, mean), how many cells are in each named state (burning) | read | `region`: json in lattice-2d (optional), `budget`: integer (optional) | json | bounded | — | no |
| `matter.at` — One cell: its material and phase, its channels in their units, and its properties where its state leaves them other than written (wet: a higher ignition) | read | `cell`: json in lattice-2d | json | bounded | — | no |
| `matter.place` — Makes a region of a material anew — every channel as a new instance of it has — in one frame, recorded with who placed it | reversible | `material`: string, `region`: json in lattice-2d | json | bounded | field.seek to the frame before it | no |
| `matter.apply` — A quantity applied to a region — a channel set to, raised by or lowered by an amount in its unit (heat: temperature add 400) — in one frame, recorded with who applied it | reversible | `channel`: string, `set`: number (optional), `add`: number (optional), `take`: number (optional), `region`: json in lattice-2d | json | bounded | field.seek to the frame before it | no |
| `matter.explode` — An explosion at a cell: a pressure over a disc and a heat at its middle — each row of it an edit of the field's, recorded with who made it. What follows is the laws' — what is brittle shatters, what is loose is thrown, what burns is lit; nothing is turned into anything by the operation | reversible | `cell`: json in lattice-2d, `radius`: integer, `pressure`: number (optional), `heat`: number (optional), `heat_radius`: integer (optional) | json | bounded | field.seek to the frame before it | no |
| `matter.heat` — A temperature set over the square about a cell, recorded with who set it | reversible | `cell`: json in lattice-2d, `radius`: integer, `kelvin`: number | json | bounded | field.seek to the frame before it | no |
| `matter.pour` — A material placed about a cell wherever there is only gas — nothing that is there is replaced — each cell an edit of the field's, recorded with who poured it; says how many cells it filled | reversible | `material`: string, `cell`: json in lattice-2d, `radius`: integer, `reach`: integer (optional) | json | bounded | field.seek to the frame before it | no |
| `matter.explain` — Why a cell is what it is: what is on record of it, the latest first — the law that held (its name, its condition, its place in the definition), what the law read, and the neighbours' parts: who gave what it needed, who took it away, what was beside it when something ran short, each followed to its own cause and to who placed or applied what — and, for a law named, whether it holds now and which comparison fails | read | `cell`: json in lattice-2d, `law`: string (optional), `depth`: integer (optional), `budget`: integer (optional) | json | bounded | — | no |
| `matter.events` — What happened, oldest first: cells that became another material (by which law), named states begun and ended (ignite, go_out), edits and their actors — since a frame, of a name, in a region | read | `since`: integer (optional), `name`: string (optional), `region`: json in lattice-2d (optional), `budget`: integer (optional) | json | bounded | — | no |
| `matter.branch` — What would be: the field some steps ahead — a material placed or a quantity applied first when given — as the materials of a region with their change, and the events that would happen, counted by name; the field itself untouched | read | `steps`: integer (optional), `place`: json in lattice-2d (optional), `apply`: json (optional), `region`: json in lattice-2d (optional) | json | bounded | — | no |

## Tasks to begin with

Each step is a request as it is sent; `describe` gives the same to an agent.

**learn-what-there-is** — Read the materials, channels and laws of this world, then the field as it is

```json
{"op":"matter.describe"}
{"op":"matter.observe"}
```

**place-and-ask-why** — Place a material, read the cell, and ask why it is what it is

```json
{"op":"matter.place","material":"water","region":[5,0,2,1]}
{"op":"matter.at","cell":[5,0]}
{"op":"matter.explain","cell":[5,0]}
```

**heat-a-spot** — Raise the temperature of a region and read what happened

```json
{"op":"matter.apply","channel":"temperature","set":900,"region":[5,0,2,1]}
{"op":"matter.events"}
```

**ask-what-would-happen** — See the field some steps ahead with a material placed first, the world itself untouched

```json
{"op":"matter.branch","steps":60,"place":{"material":"water","region":[2,0,8,2]}}
```
