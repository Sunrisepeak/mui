## 用出来的问题和处理

| 问题（对象） | 处理 |
|---|---|
| 网站的性能没有测量证据（site） | `tools/ci/site-perf.mjs` 在真实浏览器里冷启动访问，按 Pages 的方式 gzip 服务，网速 20 Mbit/s。测量传输量（总量，以及首帧前的量）、首帧时间、就绪时间、飞行中的帧间隔和内存，Pages 工作流按 `site/delivery.budget.omui.json` 卡预算。 |
| 首帧要等 4.3 MB 的格斗角色图（site） | 格斗游戏新增 `art-later` 特性：Web 构建不把角色图编进程序，页面画出首帧后再取，取到后 `arrive_art` 交给 roster，舞台随即重新绑定。dist-toy 新增 `later` 文件。首帧 5.0 s → 3.1 s，首帧前 7.0 MB。 |
| 浏览器里的无障碍没有验证（site） | `tools/ci/site-a11y.mjs` 读取 Chromium 自己的无障碍树，检查这些项：<br>• 地标（navigation、main）<br>• 一级标题<br>• 每个按钮和链接都有名字<br>• 页面声明了语言，且允许缩放<br>• 程序运行后静态页隐藏<br>• 跳过链接：Tab 第一次停在它上面，Enter 把页面和程序的焦点都移到 main |
| 跳过链接用 Tab 根本到不了（site，第一次检查发现） | 程序在 window 上监听按键，所以由页面先拿到第一个 Tab，把它交给跳过链接。在链接上按 Enter 是跟随它，按 Tab 继续交给程序。镜像给出 main 地标里第一个可聚焦的节点。有测试 |
| 标签第一次按无限宽度排版之后，再也不会换行（ui-framework：目录被截断） | `Label` 的段落一直允许换行。有测试 |
| 横向滚动的容器把比它宽的拉伸项压到自己的宽度，于是没有可滚的范围（site：示例 01 的源码） | 横向滚动时，拉伸项的宽度至少是它自己的宽度。有测试 |
| 侧栏打开后，首页的渲染面板被侧栏盖住（site D1） | 宽度不到 880 时，渲染面板排到清单下面 |
| 预演说 `styles.show` 不能撤销，实际上能（site D6） | 动词可以声明 `undoable`：函数自己把撤销步骤记进历史时，预演就如实说可以撤销 |
| 招式表的舞台一直在播放，按钮却写着“播放”（site D4） | 选中招式、防御或角色时，舞台停在出手命中的那一帧，按“播放”才播一遍，播完停在最后一帧；地方重新进入实时状态时也一样。舞台暂停时释放帧需求 |
| 实时页面里的拖动会平移整个地图（site） | 在实时节点上按下的拖动归页面，和滚轮一样 |
| 被祖先裁掉的节点没有标为 offscreen（site） | 语义状态按窗口和每个裁剪祖先的交集计算 |
| 打字之后，再重做一个旧事务，会把新打的字覆盖掉（ui-framework U3） | `Services::changed_outside_history`：历史之外的修改（打字）会让这个作用域里已经撤销的内容保持撤销。有测试 |
| 快照里一个节点的子节点列表没有上限（ui-framework U2） | `children_limit`，协议默认 256，同时返回 `children_total` |
| Markdown 的宽表格被截断，也滚动不了（ui-framework U1） | 表格放在横向滚动视图里 |
| 帧的某个阶段失败后，失败信息丢了（ui-framework） | `FrameOutput::failure` 带出失败原因；日志在信息变化时写，之后每秒最多一次；桌面端保留上一帧好的画面 |
| GPU 帧失败了，基准测试照样计时（ui-framework） | 这个基准记为 failed，检查不通过 |
| 墨和刻用手指戳的招式（fighting-presentation） | 刻的 5LP/2LP/j.LP 改成拳；墨的 L3 改成掌根 |
| 直接进入对战（`--fight`）时，选人界面抢走了键盘（fighting-presentation） | 选人界面等到第一帧、属性都绑定好之后才决定要不要拿焦点。有测试 |
| 被投时，角色的动画走的是比赛时钟（fighting-presentation） | 投技受击动画改按投技本身的时钟播放 |
| 冻结的火花离开击中点最远 ±70（fighting-presentation） | 改成 ±12 |
| 网站缺少艺术语言（site） | 全景改成一棵树：标志放在最后一个窗口后面的空格里，从它向每个地方伸出枝条，按阅读和运行着色，窗口之间铺一层网格 |
| 打砖块没有音乐（widget-breakout） | 新增一首自适应主题 `music/haunt.music.omui.toml`，F♯ 小调八音盒。连击的五声音阶音和它同调。连击、只剩最后一个球、多个球在场都会让乐器层增加。运行时的声音逐样本渲染并固定哈希，同时写出 WAV 供试听 |

## 没有复现的

- 网站手机副本在评估中途因 bus error 退出。照评分者的操作步骤重做没有复现。现在保留评估中各程序的日志（`target/eval-logs/`），下次可以直接查看。
