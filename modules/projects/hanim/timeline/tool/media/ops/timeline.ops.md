# timeline operations

Check timelines, read what plays at a moment, make the usual edits and take them back.

Generated by `omui-gen ops` from the catalog; the effect is openas's.

| Operation | Effect | Parameters | Result | Cost | Undo | Cancel |
|---|---|---|---|---|---|---|
| `timeline.check` — The timeline (rate, size, tracks and clips, markers, length), or every problem at its line and column | read | `file`: path | json | instant | — | no |
| `timeline.at` — What plays at a moment: each clip, where in its source, at what level | read | `file`: path, `time`: string | json | instant | — | no |
| `timeline.edit` — Split, trim, move, remove or ripple-remove a clip; the file written as the edit leaves it (or only said, with dry_run) | reversible | `file`: path, `edit`: string, `track`: integer, `clip`: integer, `at`: string (optional), `length`: string (optional), `to_track`: integer (optional), `dry_run`: bool (optional) | json | instant | timeline.undo | no |
| `timeline.undo` — Take back the last edit this command made to the file (its text before it restored exactly; the last 64 kept) | reversible | `file`: path | json | instant | make the edit again (timeline.edit) | no |
