# xrender operations

Check and preview pixel effects through the real GPU renderer, run the render contract's conformance suite on this machine's device, describe the device.

Generated by `omui-gen ops` from the catalog; the effect is openas's.

| Operation | Effect | Parameters | Result | Cost | Undo | Cancel |
|---|---|---|---|---|---|---|
| `effect.check` — Read each effect file, compile its shader for the device formats and register it: its parameters, or every problem at file, line and column | read | `files`: json | json | bounded | — | no |
| `effect.preview` — Draw an effect with the GPU renderer over a picture (a test card when none), before | after side by side, as PNG | reversible | `file`: path, `out`: path, `image`: path (optional), `size`: string (optional), `param`: json (optional) | json | bounded | delete the written picture | no |
| `conformance.run` — The render contract's conformance suite on this machine's device: each case against the CPU reference within its tolerance; failing pictures kept | read | `report`: path (optional) | json | heavy | — | no |
| `device.describe` — The GPU device: backend, name, whether it is software, shader formats, limits | read | — | json | instant | — | no |
