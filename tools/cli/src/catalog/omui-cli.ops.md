# omui-cli operations

The project's commands: create, build, test, check, describe, package; dependencies, tools and the design's history.

Generated by `omui-gen ops` from the catalog; the effect is openas's.

| Operation | Effect | Parameters | Result | Cost | Undo | Cancel |
|---|---|---|---|---|---|---|
| `omui.doctor` — Which tools are there and which are missing (mcpp, xlings, tsc, esbuild), and what each is for | read | — | json | bounded | — | no |
| `omui.new` — A new project from a template (app-ts by default): a directory of files, written beside the one the server runs in | irreversible | `name`: string, `template`: string (optional) | json | heavy | none: delete the directory it made | no |
| `omui.build` — Builds the project (mcpp build): its outputs under target/, nothing else changed | reversible | `release`: bool (optional) | json | heavy | none needed: target/ is the build's own | no |
| `omui.test` — Runs the project's tests (mtest): which passed, which failed and where | reversible | — | json | heavy | none needed: tests change nothing they keep | no |
| `omui.check` — Type-checks the project's TypeScript against the API it registers (tsc), or view documents: each problem at its line | read | `portable`: bool (optional) | json | heavy | — | no |
| `omui.describe` — What writing for the project takes: every builder, native module, theme token and verb, as JSON | read | — | json | heavy | — | no |
| `omui.deps` — The project's dependencies as its mcpp.toml declares them | read | — | json | instant | — | no |
| `omui.tools` — The tools the project names for xlings, and whether each is installed | read | — | json | bounded | — | no |
| `omui.config` — The project's omui.config.ts over the defaults: how far agents may go, what the recorder keeps | read | — | json | bounded | — | no |
| `omui.add` — Adds a dependency to mcpp.toml (mcpp add) | reversible | `package`: string | json | bounded | omui.remove | no |
| `omui.remove` — Removes a dependency from mcpp.toml (mcpp remove) | reversible | `package`: string | json | bounded | omui.add | no |
| `omui.package` — Packages the application for people to install (mcpp pack): an artifact written to keep and hand out | irreversible | `format`: string (optional) | json | heavy | none: delete the package it wrote | no |
| `omui.design.sync` — Carries Live Design's history into git: each design commit a commit on design/<branch>, tags as design/<tag> (the work tree untouched) | irreversible | — | json | bounded | none: delete the design/* references | no |
| `omui.design.film` — The design's history as a film (WebM): each step as it was presented, captioned | irreversible | `out`: path (optional), `branch`: string (optional), `fps`: integer (optional), `seconds`: number (optional) | json | heavy | none: delete the film | no |
