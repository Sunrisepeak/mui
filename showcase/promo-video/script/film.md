# This pixel knows what it is

openmui's film, sixty seconds at 60 frames a second, made with openmui.

| | Chapter | What it shows |
|---|---|---|
| 0:00 | Hook | one pixel and what it belongs to |
| 0:04 | Title | the semantic tree becomes the wordmark |
| 0:08 | Code | four languages, one tree |
| 0:16 | Infinite | a thousand windows in one shot |
| 0:28 | Styles | five style packs, one tree |
| 0:36 | Agent | every action knows its consequences |
| 0:46 | Time | the film rewinds itself |
| 0:55 | End | `mcpp new hello --template openmui` |

Every shot is a live openmui scene, drawn on the headless host. The film is
`promo.timeline.omui.toml` and the scenes' C++: any frame renders on its own,
the same bytes every time.
