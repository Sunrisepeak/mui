# gongfu operations

Make and check fighters: hurtboxes baked from the animation, contact sheets, stage pictures, art cut from sheets, the roster's balance.

Generated by `omui-gen ops` from the catalog; the effect is openas's.

| Operation | Effect | Parameters | Result | Cost | Undo | Cancel |
|---|---|---|---|---|---|---|
| `fighter.check` — Whether each fighter's baked hurtboxes are what its look and moves make now (stale ones name the command that fixes them) | read | `dir`: path | json | bounded | — | no |
| `fighter.bake` — Bake each fighter's hurtboxes from its look's animation into <name>.boxes.gongfu.toml | reversible | `dir`: path | json | bounded | the files are derived: restore the previous ones from version control (or bake again from the sources) | no |
| `fighter.embed` — Write the fighters as a module partition for a program; refused while a bake is stale | reversible | `dir`: path, `module`: string, `namespace`: string, `out`: path | json | bounded | delete or restore the written file | no |
| `fighter.sheet` — A contact sheet of a fighter's clips with their boxes, frame by frame, as PNG | reversible | `dir`: path, `name`: string, `out`: path, `clips`: string (optional), `frames`: string (optional), `cell`: number (optional), `columns`: integer (optional), `boxes`: bool (optional), `palette`: integer (optional) | json | bounded | delete the written picture | no |
| `stage.picture` — A stage as a frame of the game: its layers, two fighters for scale, the camera framing them as the game does | reversible | `dir`: path, `name`: string, `out`: path, `fighters`: string (optional), `at`: number (optional), `apart`: number (optional), `frame`: integer (optional) | json | bounded | delete the written picture | no |
| `art.cut` — Cut a sheet of drawn parts on a flat background into pieces: each keyed out and written as a PNG, listed with its region | reversible | `sheet`: path, `out`: path, `key`: string (optional), `gap`: integer (optional), `min`: integer (optional), `alpha`: integer (optional), `scale`: number (optional) | json | bounded | delete the written pieces | no |
| `art.picture` — A picture made ready for a look: keyed out, trimmed to what it shows, scaled to a width, written as PNG or WebP | reversible | `file`: path, `out`: path, `key`: string (optional), `trim`: bool (optional), `width`: integer (optional), `quality`: number (optional) | json | bounded | delete the written picture | no |
| `roster.versus` — Bots play every pair of the directory's fighters, sides swapped: wins, damage, supers and round length per pair; each fighter's win rate and where its damage comes from | read | `dir`: path, `rounds`: integer (optional), `seed`: integer (optional), `system`: path (optional) | json | heavy | — | no |
