# openmui.native.store

A program's own small storage (D-84 §6.2): settings, progress, a draft. Values are text, keyed by 1 to 256 bytes.

- **`Store` is the plugin interface.** A host gives its storage through it with `use_store()`. The Web host gives the page's `localStorage`, under a prefix of the application's id, so the programs of one origin (GitHub Pages) keep apart. Where no host gives one, the program keeps its values in memory (`MemoryStore`).
- **Scripts reach the same store** through the contract [`native/store.native.omui.toml`](native/store.native.omui.toml): `get`, `set`, `remove` and `keys`. The partition `src/generated/store_native.cppm` and the stubs in `stubs/` are generated by `omui-gen native`, and tools/gen's test keeps them current.
- **Calls run on the program's thread**: storage is read and written between frames, never in one.

```cpp
omui::store().set("theme", "dark");
auto theme = omui::store().get("theme");   // std::optional<std::string>
```

```ts
import { store } from "openmui:native/store";
store.set("theme", "dark");
```

Depends on `openmui.native`.
