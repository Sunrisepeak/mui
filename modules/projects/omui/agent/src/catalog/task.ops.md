# task operations

Background tasks: started with a handle at once, their progress and end readable, cancelled without waiting, the interface running all along.

Generated by `omui-gen ops` from the catalog; the effect is openas's.

| Operation | Effect | Parameters | Result | Cost | Undo | Cancel |
|---|---|---|---|---|---|---|
| `task.list` — The background tasks, newest first: each one's id, what it is, who started it, its state (running, done, failed, cancelled), its progress and how long it has run | read | `all`: bool (optional) | json | instant | — | no |
| `task.status` — One task: its state, progress (0…1, and what it is doing), and once ended its result or why it failed | read | `task`: string | json | instant | — | no |
| `task.cancel` — Cancels a task: taken at once (it answers without waiting for the work to stop), nothing the task would have committed is, and the work is asked to stop | reversible | `task`: string | json | instant | none needed: nothing it would have made was kept; start it again | no |
