# generate operations

Put generated interface into a running application: drafts checked against what it registers and how open it is, prepared, previewed as real pixels, committed as versions of a surface that undo takes back.

Generated by `omui-gen ops` from the catalog; the effect is openas's.

| Operation | Effect | Parameters | Result | Cost | Undo | Cancel |
|---|---|---|---|---|---|---|
| `generate.surfaces` — Where generated interface may go and how far: each surface the application declares (its name, what it is for, its version now), how open generation is (off, data, limited, all), the limits a draft is held to, and in limited the components and verbs it may use | read | — | json | instant | — | no |
| `generate.draft` — A draft for a surface, taken through the stages it can reach at once: validated (a view document checked against the registered components, the limits and how open generation is — every problem at its JSON pointer) and prepared (built, nothing shown). Code (limited, all) is first evaluated, sandboxed, into its document | reversible | `surface`: string, `document`: json (optional), `code`: string (optional), `language`: string (optional), `piece`: string (optional), `background`: bool (optional), `commit`: bool (optional) | json | bounded | generate.discard | no |
| `generate.preview` — A prepared draft shown without being kept: mounted at its surface unseen, the window's picture before and after (PNG) and the semantic changes it would bring, then the surface as it was | read | `draft`: string | json | bounded | — | no |
| `generate.commit` — A prepared draft made the surface's next version: mounted, its version kept with who made it, and in the history so undo takes it back to the version before. A draft made on a version the surface has moved on from is refused (its read set: what it was made over) unless `over` says to replace what is there | reversible | `draft`: string, `over`: bool (optional) | json | frame | ui.undo (the version before), or generate.restore | no |
| `generate.restore` — A surface back to a version it had (0: empty), as a new step undo takes back | reversible | `surface`: string, `version`: integer | json | frame | ui.undo | no |
| `generate.versions` — A surface's versions: each one's number, who made it, when, its draft and its document; and the one shown | read | `surface`: string | json | instant | — | no |
| `generate.drafts` — The drafts not yet committed or discarded: each one's surface, the stage it reached and its problems | read | — | json | instant | — | no |
| `generate.a2ui` — A2UI messages (v0.8's surfaceUpdate, dataModelUpdate, beginRendering, deleteSurface; one, a list, or JSON lines of a stream): the components kept between calls, each surface that renders drafted as a view document — committed too when asked, so a stream shows as it comes; what is not read yet is named, not guessed | reversible | `messages`: json, `surface`: string (optional), `commit`: bool (optional) | json | bounded | ui.undo for what it committed; generate.discard for its drafts | no |
| `generate.actions` — What the person did in generated interface, in order: each event a generated view emitted (an A2UI button's action: its name, surfaceId, sourceComponentId and context) with its number, the surface and the time — after `since` | read | `since`: integer (optional) | json | instant | — | no |
| `generate.keep` — A version kept as a piece to reuse: by name, its document (checked again whenever it is drafted), what it is for, who kept it | reversible | `surface`: string, `name`: string, `version`: integer (optional), `doc`: string (optional) | json | instant | generate.forget | no |
| `generate.pieces` — The pieces kept for reuse: each one's name, what it is for, who kept it and from where | read | — | json | instant | — | no |
| `generate.forget` — A piece no longer kept: what is shown does not change | reversible | `name`: string | json | instant | generate.keep from the version it came from | no |
| `generate.discard` — A draft let go: nothing shown changes | reversible | `draft`: string | json | instant | generate.draft with the same document | no |
